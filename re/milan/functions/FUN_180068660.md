# FUN_180068660

## Identity

- Binary: `GoodixEngineAdapter.dll` 2.0.310.900.
- Entry/body: `0x180068660..0x1800686da`.
- Role: clone a matrix header and payload into reusable destination storage.

## Behavior

Given a nonnull source and destination-owner address whose current matrix is
nonnull, the helper compares signed capacities at header `+0x0c`. If the
destination capacity is smaller, it frees that matrix and replaces it through
`FUN_180068700`, using source width `+0`, height `+4`, and element size `+0x10`.
It then copies all five dword header fields and exactly source size `+0x0c` bytes
from payload `+0x18`. The source remains unchanged.

Null source, null destination-owner address, or null current destination matrix
returns without mutation. A replacement allocation is not checked before its
header is written, so allocation failure has no recoverable status path.

`FUN_1800456b0` uses this contract for each preallocated appended-feature matrix
owner and derived mask owner. `FUN_18005d9e0` uses it for a destructively edited
working mask.

## Callees

- Allocation delegates to `FUN_180068700`; payload copying delegates to the
  runtime memcpy helper.
