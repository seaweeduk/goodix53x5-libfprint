## Recovered Behavior

It first compacts every nonzero mask slot into fixed 42-entry local arrays. Each
source row is `[x,y,0x100]`; target is `[X,Y]`. Coordinates are signed dwords in
this direct helper and are unsigned-16-bit values when materialized by
`FUN_18005b900`. It accumulates the 3x3 normal matrix and 3x2 right side with
wrapping signed 64-bit multiply/add. Every cell is then normalized independently
as wrapping `(cell+0x80)>>8`.

The nine adjugate cofactors and all later dot products use wrapping signed
64-bit arithmetic. It computes the determinant from the first matrix row,
`rounded=determinant+0x80`, `denominator=rounded>>8`, and
`half=rounded>>9`. Denominator zero returns immediately without writing the
supplied affine. Otherwise each coefficient numerator uses the corresponding
adjugate row. A nonnegative numerator is signed-`IDIV` divided as
`(numerator+half)/denominator`; a negative numerator is
`-((half-numerator)/denominator)`. Division truncates toward zero and each result
narrows to dword. The six solved words are rearranged into
`[a,b,tx,c,d,ty]`.

It then rescans all supplied pairs, not only original mask members. Each mapped
coordinate uses signed 64-bit products and `+0x80` before `>>8`, followed by
dword target subtraction and translation addition. Dword residual components
are squared into qwords and accepted only when their unsigned qword sum is
strictly below `0x64000`; there are no separate component limits in this helper.
The mean is unsigned `(sum+(count>>1))/count`, or `0x190000` for no retained
pairs. The complete refined affine replaces the input only when this mean is
strictly below the supplied robust residual and refined retained count is at
least the number of nonzero input-mask bytes. Equal residual, fewer retained
pairs, denominator zero, and all other failures are no-write outcomes. The
helper never updates the caller's mask, count, or residual.

## Dependency Unit 5 Failure Contract

The wrapper neither changes its retained count nor publishes refinement status.

malformed positive counts can overrun locals, and null mask/coordinate pointers
