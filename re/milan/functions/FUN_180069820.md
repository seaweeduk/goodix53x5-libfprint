# FUN_180069820

## Identity

- Address: `0x180069820` in `GoodixEngineAdapter.dll`, input clamp,
  profile-qualified admission, and border preparation.
- Sole caller: `FUN_18006d540`, before its setup/live branch.
- Direct profile-9 callee: `FUN_1800695e0`.
- Related current owners: `goodix_milan_preprocess_clamp_and_admit_raw` and
  `profile9_normalize_outer_edges` in `milan/core.c`.

## Profile-9 Contract

- Argument 1 is a packed descriptor of 32-bit fields: width at `+0`, height
  at `+4`, sample count at `+8`, and chip type at `+0x18`. Production type 12
  uses width 108, height 88, count 9,504, and chip type `0x0c`.
- Argument 2 is a mutable u16 frame. Argument 3 selects validation and is
  nonzero for both profile-9 setup and live calls. Argument 4 is the caller's
  validation-ready value, not exported identify/enroll purpose.
- Clamps every unsigned u16 sample above `0x0fff` to `0x0fff` before admission.
  Only chip types `0x10` and `0x12` invert samples. Production chip type `0x0c`
  never inverts; the source descriptor's separate `0x10` format byte is not
  this selector.
- Calls `FUN_1800695e0` with the full frame, signed-16-bit height and width,
  chip type, and ready value. That helper counts the two-pixel interior using
  `100 < sample < 0x0ed8` and tests `100 * admitted > percent * 8736`.
  Ready zero selects 85%; nonzero selects 15%.
- Failed admission returns `0x29bb` when ready is zero and `0x29aa` otherwise.
  The whole-frame clamp remains visible in the mutable argument, but no edge
  copies occur. Setup needs at least 7,426 admitted samples; initialized live
  needs at least 1,311.
- On success, copies row 1 to row 0 and row 86 to row 87 across all columns,
  then column 1 to column 0 and column 106 to column 107 on every row. Returns
  zero. The complete result is
  `dst[r,c] = clamped_src[clamp(r,1,86),clamp(c,1,106)]`.
- Each corner consequently comes from its diagonally adjacent inner sample,
  even when that sample is zero or `0x0fff`. Invalid inner-edge samples in
  rows 1/86 or columns 1/106 are not repaired. The two-pixel interior is
  unchanged after clamping. The nonvalidated inner-edge repair path is not
  selected by profile 9.

## Ownership And Retry

- `FUN_18006d540` allocates and copies the raw frame before this call, preserving
  the original setup/live source. On admission failure it zeros quality and
  coverage, frees the copy, and returns before setup-map construction or live
  mask, gain, classification, rendering, and quality processing.
- The admission helper reads only the current copied frame, dimensions, chip
  type, and ready value. Setup content or retained generation state cannot make
  the same rejected live frame pass while those inputs remain unchanged.
- Rejection does not roll back caller-side generation writes already performed.
  It is a retry rather than a completed preprocessing/extraction lifecycle;
  preserving its chronological call does not make its output a successful image.
- Hardware reference acquisition does not call this helper. The admitted TX-on
  reference reaches the engine with a completed live sample, and
  `EngineAdapterAcceptSampleData` requests setup for an uninitialized context
  or a sample carrying the one-shot refresh marker. Failed engine setup does
  not revoke that independently retained hardware reference.
- Successful setup normalization feeds `FUN_180064bb0`; see its note for the
  full-plane rounded mean and offset setup-map construction.
