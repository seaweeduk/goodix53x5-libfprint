# FUN_180044c90

## Identity

- Binary: `GoodixEngineAdapter.dll` 2.0.310.900.
- Address/body: `0x180044c90..0x180044fbf`, masked eight-neighbor class
  builder.
- Sole caller: `FUN_180044b50`.
- Current counterpart: the classification loop in
  `milan/core.c:quality_mask_fraction_core`.

## Behavior

The caller initializes the output class plane to 9. This leaf visits only
non-border pixels whose validity mask is nonzero. In circular order
`NW,N,NE,E,SE,S,SW,W`, it records whether each neighbor exceeds the center by
strictly more than 4. A difference equal to 4 is false.

It counts circular boolean transitions. When the count is below 3, the output
class is the number of true neighbor comparisons, in `0..8`. Three or more
transitions leave class 9 unchanged. Borders and masked-out pixels also remain
9.

Only the center mask byte is tested. All eight neighbor intensities are read
regardless of their mask bytes, unlike the complete-neighborhood admission in
`FUN_180044150`. Rewriting the quality mask therefore changes which centers
contribute without masking or replacing their neighboring image samples.

Circular binary transitions are necessarily even: the admitted transition
counts are exactly 0 and 2; rejection begins at 4. Uniform-zero and uniform-one
rings produce classes 0 and 8 and remain in the percentage denominator. A ring
with four true comparisons contributes to class 4 only when those comparisons
form a single contiguous circular run. See `FUN_180044b50` for the mask-gated
histogram and denominator; neither routine mutates the source image or mask.
