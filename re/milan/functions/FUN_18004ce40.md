## Exact Contract

Inputs are a signed-16 image, byte-valid mask, pixel count, subtype, and an
upper threshold cap. The helper finds the valid signed minimum and maximum and
builds a 256-bin linearly interpolated histogram exactly as follows:

```text
range = maximum - minimum
scaled = (sample - minimum) * 255
bin = scaled / range
remainder = scaled - bin * range
hist[bin] += range - remainder
if bin < 255: hist[bin + 1] += remainder
```

An invalid argument returns `0x80000002`. A nonpositive range writes both
thresholds as `minimum` and returns `0x80000003`.

For a positive range it calls `FUN_180050f70`, then passes the clipped
histogram/state to `FUN_18004e0e0`. The latter's return is the primary state. If
that return is 2, the Otsu bin returned through the helper is mapped back with
`(clipped_range * bin + 128) / 255 + clipped_min` and stored next to the state.

Independently, the wrapper computes the original-histogram 35th and 50th
percentile bins using cumulative targets `floor(total * 35 / 100)` and
`floor(total * 50 / 100)`. Both are mapped with `+128` rounding. It also maps
the earliest original mode bin with `+128`, caps that mode-derived value at the
caller cap (8192 in `FUN_18004d510`), and caps both percentile outputs to it.
