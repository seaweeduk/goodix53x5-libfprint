## Exact Algorithm

Return 0 unless the clipped histogram's original mode bin is in 10..251 and its
range is positive. Otherwise form `h[i] = input[i] >> 5`, apply the same two
21-bin smoothing passes and 10/245 edge extension documented for
`FUN_18004e0e0`, and retain the second-pass 21-bin sums as `box[]`.
The shift is signed `PSRAD`; each average is signed `(sum + 10) / 21`.
The box edges remain zero, and smooth edges are extended only after the second
pass. Input histogram storage is unchanged; smoothing planes are call-local.

Select the earliest strict maximum of `box[]` as `global_peak`, retaining the
incoming mode bin if all box entries are zero. Continue only
when:

```text
box[global_peak] * 100 <= (total_weight >> 5) * 35
```

Set `exclusion = 128000 / range`. Visit bins 10..245 in ascending order outside
the open exclusion interval around `global_peak`; both endpoints are eligible.
The offset table is
`{-10,+10,-9,+9,...,-1,+1}`. A candidate returns state 1 only when all are true:

```text
smooth[i] >= smooth[i+d] for every table entry d
prominence = smooth[i]
           - max(smooth[i] * 5 / 100, smooth[global_peak] / 100)
smooth[i-10] <= prominence and smooth[i+10] <= prominence
box[i] * 100 >= box[global_peak] * 25
valley * 100 <= box[i] * 85
valley * 100 <= box[global_peak] * 60
```

`valley` is the minimum `box` value on the half-open interval between candidate
and global peak. If no candidate passes, return 0. This helper has only states 0
and 1.

An excluded position or failed local-maximum test advances by one. After the
local-maximum test passes, a later predicate failure advances by eleven: ten
at `0x18004fdd6..0x18004fdde` plus the common increment at
`0x18004fde2..0x18004fde8`.
