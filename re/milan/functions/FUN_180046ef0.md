# FUN_180046ef0

- Entry/body: `0x180046ef0..0x18004711a`.
- Role: select the largest geometric footprint when the capacity replacement
  selector has no primary candidate.

## Call Path

`FUN_1800469f0` calls this helper only after `FUN_180045530` returns `-1` and
the retained-evidence flag at evidence `+0x644` is nonzero. The helper itself
does not inspect that flag. Its direct callees are affine inversion
`FUN_1800689a0`, affine composition `FUN_180068860`, and footprint-area helper
`FUN_180071370`.

The caller accepts a returned candidate when its signed percentage is at least
`80`, or when it is at least `60` and template counter `+0x8cf8` is strictly
greater than `1000`. Therefore `79/1000` and `60/1000` reject, while `80/1000`
and `60/1001` accept. A returned index below zero always rejects.

An accepted geometric candidate becomes action `3` only when retained flag
`+0x644` is exactly `1`. Other nonzero flag values do not produce action `3`;
they continue through the caller's non-action-3 replacement policy.

## Producer Reachability

Profile-9 enrollment and capacity normalization can leave an established graph
with only two active features, the reference and one other feature, and positive
residual `+0x128` on both. Packing and fresh unpacking preserve this state;
capacity does not imply the existence of an active zero-residual feature.

For retained flag one, matching the reference in such a graph need not admit a
primary replacement. A positive matched residual bypasses the primary helper's
immediate-match return. The only active nonreference feature is then its ranked
candidate. If the reference footprint covers the probe mask, excluding that
candidate leaves zero probe residual. Before the age allowance applies, zero
is strictly below the candidate's positive residual, so `FUN_180045530` returns
`-1`. Geometric selection still includes the reference: an identity
probe-to-reference transform gives it the complete `2288`-cell footprint and
`100` percent. This path returns action `3` through normal identify/study after
fresh unpack; it does not require retained queue owners or a prior Action 0.

## Selection

The helper initializes the output index to `-1` and raw best area to zero. It
scans feature indices upward and admits exactly features with active word
`+0x110 != 0` and state word `+0x124 != 5`.

For each eligible feature, it constructs the reference-to-feature transform:

- Feature equal to reference `+0x87d8`: identity.
- Feature below the reference: copy the stored star affine.
- Feature above the reference: invert the stored star affine.

The stored edge's leading word is not tested. A missing star edge therefore
uses the identity affine already present in the relation slot. The helper
composes the reference-to-feature affine after evidence probe-to-reference
transform `+0x66c`. In profile-9 half-resolution mode it then arithmetic-shifts
only translations `t2` and `t5` right by one.

`FUN_180071370` measures the resulting probe-to-feature footprint over the
half-resolution template domain. Ranking uses the raw returned area, not a
percentage. A candidate replaces the winner only when `area > best_area`, so
equal areas keep the earlier feature and zero-area features never become a
winner.

After the scan, the helper writes:

```text
percent = wrap32(best_area * 100) / wrap32(rows * columns)
```

Both products wrap as dwords and signed division truncates toward zero. The
profile-9 domain is `52 * 44 = 2288`, so ordinary areas are `0..2288` and the
result is `0..100`.

## Ownership And Failure

The helper reads gallery features, reference-star relations, and the evidence
transform. It writes only the caller-owned selected-index and percentage
outputs plus stack workspace. It does not mutate a feature, relation, counter,
queue, or template owner and has no status return.

Zero eligible features and eligible features with only zero area both leave
index `-1` and percentage `0`. The fixed profile-9 dimensions keep the final
division denominator nonzero. Affine helpers preserve their own wrapped and
singular-input behavior; this helper adds no rejection or saturation.

through `FUN_1800458c0`, and installs the evidence relation through

counter, queue, export, and persistence tail; the geometric helper does not own
