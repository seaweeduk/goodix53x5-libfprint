## Histogram And Footprint Boundaries

The histogram includes valid patches with score zero. Rejected patches are
stored as `-1` and cannot mark the mask; a skipped zero-mask center does not
enter the stored patch list. Each stored valid score is its truncated integer
percentage, so distinct Q16 scores in one bin all participate in the same tie.
The median target is `floor(valid_patch_count/2)`, with a `>=` cumulative test
starting at bin zero (`0x180044053..0x180044071`). Consequently zero or one valid
patch selects bin zero even if that one patch has a positive score. No
positive-score patch then marks the mask. This is not an upper median or a
one-based median rank.

At width 108/height 88, centers are columns 12..92 and rows 12..68, in increments
of 8. Scoring includes both endpoints, from center-12 through center+12;
rewriting covers center-12 through center+11. Thus no scoring patch reaches
columns 105..107 or rows 81..87, and no rewrite footprint reaches columns 104..107
or rows 80..87. Those trailing mask bytes are cleared by final normalization.
Overlapping chosen footprints form a union over the original nonzero support:
marker 32 remains nonzero for later footprints. The final pass keeps exactly
marker 32, so the production caller's binary 0/255 mask has no preexisting marker
that could survive without being touched.
