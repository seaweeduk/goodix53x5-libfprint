# FUN_1800512c0

## Identity

- Profile-9 retained reference/support updater at
  `0x1800512c0..0x1800514cc`.
- Reached from `FUN_1800508a0` when selected-plane value is not 2 and the direct
  seed branch is not taken.

## Contract

- Computes `v = s16(3 * (s16(delta) - 4095))`, then stores `max(v,0)`
  as a word. Narrowing precedes the signed-negative clamp.
- When source frame count is below two, resets reference count to zero and the
  adaptive coverage threshold to 60.
- Update admission is strict:
  `mask_count * 100 > adaptive_threshold * 9504`.
- On admission, threshold rises by five, caps at 85, and resets to 60 when the
  running admitted-coverage average is strictly above 80.
- The normalized reference is averaged with prior reference using the old
  count. Reference count then increments and caps at 50.
- Support age increments only for mask byte exactly 1, decrements only for byte
  exactly 0, and caps at 50. Other byte values leave it unchanged.
- Rejected updates change no retained reference/support state except the
  source-count-below-two reset.

For an admitted update, let `N=9504`, `c` be the old retained count,
`v[i]` the nonnegative narrowed temporary above, and
`mean = sum(v[i]) / N`, with signed-dword division truncating toward zero.
When `mean` is nonzero, each reference word becomes

```text
s16((trunc((v[i] << 13) / mean) + s16(old_reference[i]) * c) / (c + 1))
```

Both divisions are signed and truncate toward zero. The old reference operand
is sign-extended from a word; the result is narrowed to a word without a clamp.
The decisive sequence is `MOVSX ECX,word ptr [RBX]` at `0x180051437`,
old-count multiplication at `0x18005143a`, signed divisions at
`0x180051446` and `0x18005144f`, and the low-word store at `0x180051451`.
If `mean` is zero, all reference words remain unchanged, but the admitted
coverage threshold/average, support ages, and retained count still update.
The source/reference arrays and support ages are separate allocations, so
updating one pixel cannot change another pixel's source or old reference.

This adaptive reference gate is independent from `FUN_18004f540`'s fixed 75%
component-age gate. A coverage-67 call may move reference/support history while
component ages remain frozen.

## Caller Seed And Classification Order

`FUN_1800508a0` prepares the signed-word delta and eroded-valid mask through
`FUN_18004ee80` before choosing the reference update. With ordinary selected-plane
entry zero, retained reference count zero and source sample count greater than
one take a direct seed branch instead of this updater: copy all 9,504 calibration
words from workspace `+0x04`, set reference count to `min(sample_count,21)`, and
fill every support-age byte with that count. This branch does not change the
adaptive threshold or running admitted-coverage average. Selected-plane entry
two skips both seeding and this updater.

The ordinary initialized type-12 setup/live producer bounds the prepared delta
by `3000..11190`, hence the updater's nonnegative temporary by `0..21285`.
Its pre-clamp multiplication therefore does not wrap on that producer domain.
For a nonzero mean and an exported retained count at most 50, the shifted
temporary, signed old-reference product, and their sum all fit signed dwords;
the final reference word still has no saturation or nonnegative guarantee.

Fresh calibration initialized to zero or 8192 has a narrower seed invariant.
`FUN_180067050` accepts type-12 candidate values only in `1601..14399` and uses
a rounded convex running average with the old unsigned calibration word.
Induction bounds that fresh calibration by `0..14399`, and direct seeding
preserves the bound. This is not an invariant for arbitrary imported reference
words, nor a proof that all later normalized-reference updates preserve it.
See `FUN_180067050.md` for calibration admission and `FUN_1800501d0.md` for the
independent signed reference import.

Reference update or seed precedes `FUN_18004d510`. The subsequent secondary and
temporal path `FUN_18004e8c0` runs only when the resulting reference count exceeds
20, using the just-updated reference/support ages and the same eroded-valid mask.
Its fallback `FUN_18004dea0` reads the calibration plane only when both secondary
state words (`context +0x04` and `+0x08`) are zero and the direct seed branch was
not taken. That fallback changes the secondary scalar states, not the temporal
class-three assignments already made by `FUN_18004e8c0`.

After the interior low-live-value class-three pass and directional-state
calculation, the caller serializes reference, ages, counters, and the current
extraction ring through `FUN_18004ff40` at `0x180050ed3`, then sets the import
latch. Final preprocessing retry and later extraction do not roll back this
reference update. See `FUN_18004e8c0.md`, `FUN_18004ff40.md`, and
`FUN_180048260.md` for the distinct scalar, snapshot, and extraction mutations.
