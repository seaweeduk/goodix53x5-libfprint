## Histogram Preparation

The input is the 256-bin histogram and state emitted by `FUN_180050f70`.
Return 0 immediately when signed clipped `mode_bin < 10` or clipped signed-16
`range <= 0`. The dword at state `+0x08` is the mode bin, not the active sample
count; the signed range is the word at `+0x0c`.

Otherwise:

```text
h[i] = input[i] >> 4
repeat twice:
    for i in 10..245:
        box[i] = sum(h[i-10..i+10])
        smooth[i] = (box[i] + 10) / 21
    for i outside 10..245: smooth[i] = h[i]
    h = smooth
for i in 0..9:     smooth[i] = smooth[10]
for i in 246..255: smooth[i] = smooth[245]
```

`box[]` is the 21-bin sum from the second pass. The global box peak is the
earliest bin whose `box` value is strictly greater than the previous maximum.

## Broad And Split States

Find the contiguous width around the global box peak for which `smooth` is at
least `floor(smooth[peak] * 20 / 100)`. The upper search stops at 246. The lower
search stops at 10: if every tested bin through bin 10 meets the floor, the
lower bound remains 10 rather than becoming 9. Preliminary state becomes 1
when any of these strict pairs is true:

```text
upper = 246
for i = peak; i < 246; i++:
    if smooth[i] < floor:
        upper = i
        break

lower = 10
for i = peak; i >= 10; i--:
    if smooth[i] < floor:
        lower = i
        break

width = upper - lower
```

The upper result is therefore at most the sentinel 246; bin 246 is not tested.
The width and signed-16 range comparisons below are strict signed comparisons:

```text
width > 180 and range > 1200
width > 200 and range > 1000
width > 230 and range > 800
```

Starting at bin 128, find the largest `smooth` peak in 128..245 and 128..10. A
side only replaces bin 128 when its value is strictly greater than
`2 * smooth[128] + 1`. The tests below then use the second-pass `box` masses at
those selected bins. Preliminary state also becomes 1 when all are true:

```text
range > 1000
high_peak - low_peak > 210
box[low_peak] * 100 > (total_weight >> 4) * 10
31 <= (box[low_peak] * 100 + 100) / (box[high_peak] + 1) <= 332
```

The ratio bounds are the exact unsigned test produced by
`ratio - 31 <= 301`.

## State-2 Isolated Peak

Subtype 16 returns the preliminary state unless it is already 1. Type 12 always
continues. Set `exclusion = 51200 / range` and inspect candidate bins 10..245
outside the inclusive global-peak exclusion interval. Candidates are visited in
ascending order and must satisfy all of:

```text
smooth[i] >= smooth[i+d] for d in {-10,+10,-9,+9,...,-1,+1}
prominence = smooth[i] - smooth[global_peak] / 150
smooth[i-10] <= prominence and smooth[i+10] <= prominence
box[i] * 100 >= box[global_peak] * subtype_mass_percent
valley * 100 <= box[i] * 85
valley * 100 <= box[global_peak] * 60
```

`subtype_mass_percent` is 30 normally and 40 for subtype 16. `valley` is the
minimum `box` value on the half-open interval between candidate and global
peak. On the first accepted candidate, call `FUN_18004f300(smooth)`, return its
bin through the output pointer, and return state 2. If none is accepted, return
the preliminary 0/1 state.
