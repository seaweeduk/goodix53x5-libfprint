## Matrix Layout And Ownership

Feature pointers start at gallery `+0x28`; live count is `+0x1c`, reference
index is `+0x87d8`, and relation storage starts at `+0x1b8`. Each relation
contains a signed leading dword and six affine dwords, stride `0x1c`.
For physical indices `i<j`, the canonical slot is `feature[j].b6+i`, where
`b6` is feature `+0x114`. Stored direction is higher-index to lower-index.
The unset slot is `[-1,256,0,0,0,256,0]`.

The selector passes evidence affine `+0x66c`; no relation count is passed or
consulted. The function changes relation slots only. It does not change feature
counts, row bases, reference identity, graph-established state, masks, ordering,
or lifecycle fields. The serializer preserves the stored canonical direction.

## Nonreference Target

The helper resets every target-incident relation to the unset identity, first
lower physical indices, then higher indices. It then sets the target/reference
slot's leading word to zero and stores:

- target above reference: the supplied affine directly;
- target below reference: its inverse.

Clearing covers incident non-star edges as well as the reference edge. Zero is
a defined leading word and is eligible for reference-star serialization.
The target's relation-row base and reference index determine the slot; the
matched feature index and any matcher relation count do not participate.

## Reference Target

Let `X` be the supplied new-reference-to-old-reference transform and `S` an
existing canonical reference-star affine. The function computes `inverse(X)`
once, then visits lower indices followed by higher indices:

```text
lower feature:  S := compose(S, X)
higher feature: S := compose(inverse(X), S)
```

Only slots with signed leading word `>=0` are visited. Both leading word and
slot cardinality remain unchanged; negative-leading slots retain every byte.
The tests are `CMP leading,-1; JLE` at `0x180045ddf..0x180045de3` and
`0x180045e43..0x180045e47`. Lower composition is at
`0x180045de5..0x180045df5`; upper composition is at
`0x180045e49..0x180045e5b`.

The exact operation order matters: lower slots are composed directly, without
inverting `S` or inverting the composition result. Integer inversion truncates
and composition normalizes, so an algebraically equivalent sequence need not
produce the same fixed-point words. The related current owner is
`goodix_milan_relation_matrix_reanchor` in `milan/relations.c`.

## Caller Ordering And Failure

On first-graph append the caller sets the matched index as reference before
installing the new highest-index feature's relation. Append calls this helper
only when matched `b5` is exactly one after graph establishment. Later retained
refresh may reanchor that relation; its independent ordered-entry contract is
in `FUN_180046430.md`.

Actions 3/4 invoke this helper after feature replacement and before whole-gallery
normalization. Reference replacement preserves incident relations in the
replacement helper, allowing this function to compose them. Nonreference
replacement already clears incidents and this helper clears them again before
installing the reference edge. Action 2 leaves replacement's incident handling
as the final relation state. See `FUN_1800469f0.md` and `FUN_1800458c0.md`.

This function is void, performs no index/row-base validation, and has no status,
rollback, or caller failure branch. Affine inversion/composition retain their
own arithmetic and singular-input behavior.
