selected neighborhood. If at least 50 zero pixels exist globally, records whose

optional mode also clears the caller's full-resolution validity matrix wherever
the local count is nonzero.

whose local count is greater than one.

The cleared matrix is the temporary descriptor passed as argument 3 at
`FUN_18004ae70:0x18004b599..0x18004b5fa`. It is not the owned `52x44` matrix at

Record coordinates at offsets `+2/+4` are rounded from Q8 with `(value + 0x80)
>> 8`. They were materialized on the centered `104x88` image created by
`FUN_180070690`, which drops two columns from each side of the `108x88` input,
but this helper indexes the `108x88` mask with the rounded coordinate directly:
it does not add the two-column crop offset. The optional feature-mask clear uses
the same unshifted `x=0..103`, `y=0..87` coordinate pairing.

Removal is in-place swap-with-tail. When the removed record is not already the
last live record, the last record replaces it, the old tail slot is zeroed, and
the replacement is re-evaluated at the same index. Removing the last live
record only decrements the count; that now-dead slot is not zeroed. The process
can therefore change both count and canonical pre-partition order.
