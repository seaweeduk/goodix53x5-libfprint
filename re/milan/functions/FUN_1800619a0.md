## Production Source Boundary At `c182b140`

`1 + high*(high-1)/2 + low` and scans the sparse packed relation array. Its two
public adapters intentionally have different missing/state contracts:

- `goodix_milan_template_reference_transform()` requires an established graph

  Word zero is always the clean-room sentinel zero on every non-error return;
  words 1 through 6 are the routed affine. Equal feature/reference returns the
  direct affine with status zero, and a found edge routes it with status zero.
  An established missing edge returns identity with status one without routing
  the direct affine. The exact graphless tuple `f5=0, f2=-1, relation_count=0`
  likewise returns sentinel-zero identity with status one. Invalid state returns
  `-1`.

`relation_values[0]` does not. Native has no seven-word adapter: this function
writes only the six affine dwords at `+0x66c`, while the caller independently
writes count `+0x668`.
