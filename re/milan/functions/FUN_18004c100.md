## Type-12 Discovery

plane pointer at `+0x18`. The scale input is an array of matrix pointers with
unsigned-16 planes. Type 12 scans scales `1..3`, rows `6..rows-7`, and columns
`6..columns-7`, in that nesting order, ascending. Fixed post-crop geometry is
104 columns by 88 rows, giving 20,976 scanned points.

32-bit response output before testing `abs(response) > 0x148`. Its 26 neighbor
differences are unsigned-16 operands subtracted in 32 bits without narrowing.

## Refinement And Handoff

Each discovered point supplies x, y, scale, and response to
`FUN_18004c5a0`. The caller clears curvature and candidate scale value before
the call (`0x18004c25d`, `0x18004c26a`); it does not clear the candidate's Q8
x/y words. Successful refinement overwrites both Q8 words before consumption.
Rejected candidates never reach the primary materializer.

After successful refinement, a caller-cleared byte plane suppresses duplicate
final integer `(x,y)` coordinates across all scales. Original coordinates and
Q8 coordinates do not key this plane. The first successful candidate owns the
pixel. The native materializer receives the source pointer at that final pixel,
the complete candidate, output arrays, running count pointer, gradient matrices,
capacity, and type 12. Curvature is not passed and is not an admission gate.
Type-12 materialization appends exactly one record per call; foreground,
histogram peak, and secondary-orientation fields are outputs, not additional
admission predicates. The converged one-pixel interior bounds keep the source
neighborhood valid even after movement leaves the six-pixel scan interior.
After materialization the pixel is marked visited, then the scan stops if the
returned count is at least capacity (`0x18004c4ea..0x18004c4fb`). Production
capacity is 300; the bound is a positive signed-32 post-append comparison.

The current count-query/fill decomposition must preserve this ordered handoff
for immutable planes. Its standalone discovery query returns the full count
while writing only the requested prefix; materialization allocates the exact
count, repeats discovery, and refines until its accepted unique count reaches
capacity. Native discovery uses fixed scratch and performs no allocation here.
At fixed geometry the current extrema storage is bounded by 335,616 bytes,
plus 9,152 visited bytes. Either allocation failure returns zero; native has no
recoverable allocation result at this owner. Empty materialized counts are
permitted and the outer caller owns the retry decision.
