# FUN_180030040

## Audit Scope

Sensor-profile predicate called by `FUN_18002b240` after it receives the
hardware-provided sensor type. This note was created before first Ghidra
inspection during the independent methodology audit.

## Questions

- Does sensor type 9 enable production enrollment preprocessing?
- Which profile values take the alternate path?

## Audit Findings

- Types `0..2` return `0`, types `3..8` return `2`, and type `9` returns `1`.
- The production adapter calls `preprocessor` for enrollment only when this
  predicate returns `1`; type 9 therefore takes the active enrollment path.
