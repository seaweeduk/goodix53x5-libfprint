## Packet Contract

- Requires workspace signature `0x24cc7bf4f728f6f4` at `+0x26488` and version
  `0x2711` at `+0x26490`.
- Imports history-plane count at `+0x26494`, component-age count at `+0x26498`,
  and reference/support count at `+0x2649c`.
- Each word at `+0x264a0` packs three two-bit history values, four-bit component
  age, and six-bit support age.
- A 44x54 reference plane follows the 9,504 packed words and is bilinearly
  reconstructed to 88x108.
- The first argument uses the descriptor layout in `FUN_18004ff40`. Import
  writes its version and three counts, all 9,504 bytes of each destination
  history-plane prefix (stride `0x4c90`), both age arrays, and all 9,504 reference
  words. Pointer and dimension fields, history-plane tails, and the source
  workspace packet remain unchanged. The packed reference is copied to a
  temporary buffer, reconstructed, and freed.
- Reconstruction calls `FUN_180052380` with affine `[512,0,0,0,512,0]`, source
  dimensions 44x54 and destination dimensions 88x108. Signed source words are
  sampled at `(row/2,column/2)`, with fractions 0 or 128 in Q8. Four available
  neighbors use the Q16 weighted sum plus `0x8000`, shifted right 16 and stored
  as the low 16-bit word. On this signed-word output the native logical shift
  and an arithmetic shift have identical low 16 bits.
- At the last two destination rows or columns, fewer than four source neighbors
  exist. These outputs use the signed sum of all available neighbors divided
  by their count, truncating toward zero, regardless of the coordinate's parity.
  The bottom-right 2x2 output therefore repeats the last source word; no
  profile-9 destination coordinate reaches the zero-neighbor fallback.
- Import ends after that reference at packet-relative `+0x5ce8`. The remaining
  `0x4318` bytes in the persisted `0xa000` block are not packet fields and are
  not read by this function.
- Imported scalar counts are trusted. Valid native exports cap history planes at
  3, component ages/count at 5, and support ages/reference count at 50.
- Workspace `+0x26488` is the address `DAT_18023faf8`. The official calibration
  serializer copies `0xa000` bytes from this address to payload `+0x1848c`, and
  the loader restores them before `preprocessor_init`. The packet is therefore
  retained across attachments, not merely across live calls in one workspace.
- The successful setup save in `FUN_18002bfa0` transports that loaded packet
  unchanged. Type-12 setup returns before `FUN_1800508a0`, so it neither runs
  this importer nor serializes reconstructed globals through `FUN_18004ff40`.
  Reference reconstruction occurs at the first live classifier entry while the
  import latch is zero; the subsequent classifier-end serialization creates
  the next packed reference. Setup's immediate save therefore does not itself
  introduce another downsample/reconstruction cycle.
