## Recovered Behavior

For Q8 matrix words `[a,b,tx,c,d,ty]`, it first computes
`det = wrap32(a*d - b*c)`. Both multiplies, the subtraction, and the zero test
are explicitly 32-bit. A wrapped-zero determinant copies all six input words
unchanged; the function has no error return.

For nonzero `det`, sign-extended to 64 bits, it computes:

```text
out0 = idiv64(wrap64(d << 16), det)
out1 = idiv64(wrap64(-b << 16), det)
out2 = idiv64(wrap64((ty*b - d*tx) << 8), det)
out3 = idiv64(wrap64(-c << 16), det)
out4 = idiv64(wrap64(a << 16), det)
out5 = idiv64(wrap64((c*tx - ty*a) << 8), det)
```

Translation products and subtraction are signed 64-bit with wrap, followed by
a wrapping 64-bit shift. `IDIV` truncates toward zero. Each quotient narrows to
its low signed 32 bits. There is no normalization, saturation, range check, or
rounding bias. Input/output aliasing is supported because all six inputs are
loaded before stores.

Evidence is the complete leaf body at `0x1800689ce..0x180068aa9`.

Direct controls cover identity, translation, rotation/scale, positive and
negative fractional quotients, negative coefficients, wrapped translation
numerators, ordinary singular input, determinant-only 32-bit wrap to zero, and
in-place inversion. All are exact. In particular,
`[65536,0,1,0,65536,2]` is copied unchanged because its mathematical
determinant `2^32` wraps to zero.
