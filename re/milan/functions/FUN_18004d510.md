## Exact State Production

The prepared signed-16 plane is filtered separably with Q16 kernel
`[6980, 51576, 6980]` and reflect-101 borders. `FUN_18004ce40` classifies the
filtered plane under the mask eroded by eight samples per edge. Its return state
0, 1, or 2 is written to classifier context `+0x00`; this becomes auxiliary
byte 0.

The function then builds classes 3, 1, and 2 in that order and invokes
`FUN_18004f540` for retained component class 1. The exact class pipeline is
already represented by `goodix_milan_profile9_build_broken_mask()`.

There is one final generic override when the histogram state is below 2 and an
auxiliary decision plane was requested:

```text
classified_count = count(class_plane[i] != 0)
classified_sum = sum(filtered[i] where class_plane[i] != 0)
if classified_count * 100 > active_mask_count * 30:
    threshold = (classified_sum + classified_count / 2) / classified_count
    rebuild the optional decision plane using threshold
    primary_state = 2
```

The strict 30% comparison is against the caller's active contrast-mask count,
not all 9,504 pixels. The sum uses signed-16 filtered samples and a signed-32
accumulator; division truncates toward zero after adding half the count.
The decision-plane rebuilding does not alter the class plane or counts.

For a direct state-2 result, `FUN_18004ce40` publishes the state in output dword
0 and the clipped-domain Otsu threshold in output dword 1. `FUN_18004e0e0`
passes its twice-smoothed, edge-extended histogram to `FUN_18004f300`, which
normalizes each bin to Q16 by truncating division, scans thresholds0..254,
and keeps the first strictly maximal between-class score. The source threshold
is `clipped_minimum + (clipped_range * threshold_bin + 128) / 255`.

The optional buffer is cleared for exactly rows*columns bytes, beginning at
its base. For state2, each **eroded-valid-mask** sample becomes1 when the
signed filtered value is strictly above the threshold, otherwise2; invalid
samples remain0. This first write follows class2 construction and precedes
`FUN_18004f540`. The strict30% override follows that retained-component
mutation and rewrites the same buffer with the mean threshold and the same
eroded-valid mask. The classifier context receives primary state independently
of later summary overwrites by `FUN_18006b290`.

This decision plane remains distinct from the broken-class plane. The writer
does not add an eight-byte header: extraction samples the buffer base,
as specified in `FUN_180048260.md`. On direct extraction
