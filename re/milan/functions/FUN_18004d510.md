A sufficient empty-prelude condition is available directly from those gates.
Let M be the maximum nonnegative `FUN_180052b80` score and A its rounded mean
over positive scores. If `0<M<240`, `5*A>M`, and every eroded-valid filtered
sample is at least the lower histogram threshold, the class plane is still
entirely zero at component entry. Both adaptive averaging sets then contain all
positive scores. Their seed thresholds are at least `min(5*A,800)` and
`min(5*A,240)`, respectively, each strictly above M, so neither supplies a seed.
Edge refinement and invalid filling cannot create a seed from those empty
masks; the published-count density gate is false. The class2 start predicate
excludes every valid pixel. The same conclusion holds for M=0 with that class2
exclusion. This condition places no bound on the one-step component population.

There is one final generic override when the histogram state is below 2 and an
auxiliary decision plane was requested:

```text
classified_count = count(class_plane[i] != 0)
classified_sum = sum(filtered[i] where class_plane[i] != 0)
if classified_count * 100 > active_mask_count * 30:
    threshold = (classified_sum + classified_count / 2) / classified_count
    rebuild the optional decision plane using threshold
    primary_state = 2
```

The strict 30% comparison is against the caller's active contrast-mask count,
not all 9,504 pixels. The sum uses signed-16 filtered samples and a signed-32
accumulator; division truncates toward zero after adding half the count.
The decision-plane rebuilding does not alter the class plane or counts.

without changing a single severe-mask byte. `FUN_18006b290` consumes that state
before returning: state2 enables its strict class3-count-over-10%-of-active
retry condition, independently of the unconditional strict30% severe-count
condition. It also increments the secondary summary when primary state is2.

current mode and packed high class; mature class1 history promotes seed1 to
