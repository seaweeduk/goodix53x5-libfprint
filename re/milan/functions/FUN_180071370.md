# FUN_180071370

## Identity

- Binary: `GoodixEngineAdapter.dll` 2.0.310.900.
- Entry/body: `0x180071370..0x180071507`.
- Role: compute the exact number of destination cells whose affine-mapped
  coordinates remain inside a source rectangle.
- Direct callee: signed interval solver `FUN_180073090`.

## Contract

The arguments are destination rows, destination columns, source rows, source
columns, a six-dword Q8 affine `[a,b,tx,c,d,ty]`, and caller-owned workspace.
For each destination row `y`, the helper forms both row origins with wrapping
dword multiply/add and calls `FUN_180073090` twice. When those dword operations
do not overflow, the returned inclusive intervals are exactly the columns
satisfying:

```text
0 <= x*a + y*b + tx <= source_columns*256 - 256
0 <= x*c + y*d + ty <= source_rows*256 - 256
```

It intersects those intervals, clamps the first column to at least zero and the
last column to at most `destination_columns - 1`, and accepts the row when
`first <= last`. Accepted rows store their inclusive interval in workspace,
update the first and last nonempty destination rows, and add
`wrap32(last - first + 1)` to a wrapping dword area accumulator.

The return value is the accumulated area. Workspace word zero receives the
first nonempty row and word one receives the last nonempty row. Empty input or
no accepted row returns area zero with the initialized row bounds.

All row-origin and interval-endpoint multiply/add expressions, comparisons,
bounds, and area accumulation use signed dword values. Overflow can therefore
change the interval solver's monotonic assumptions; there is no saturation or
overflow guard. A caller that halves profile-9 geometry arithmetic-shifts only affine
translations before calling this helper; the helper does not apply profile
selection itself.
