## Behavior

Computes transformed row/column clipping intervals and returns the total number
of in-bounds cells. For each destination row it calls `FUN_180073090` twice to
derive valid source-index intervals, intersects them with image bounds, stores
the interval in the workspace, tracks first/last nonempty rows, and accumulates
cell count.

The policy-facing transform coordinates, bounds, and interval-area accumulation
use wrapped signed dword intermediates. Translation reduction uses arithmetic
right shift; clipping and threshold comparisons are signed. Callers that convert
the returned area to a percentage wrap the `area * 100` product and use signed
division truncating toward zero. Production commit `89dd6c43` preserves these
width and signedness rules in the clean-room study footprint path.

`FUN_180047120` passes that returned cell count through unchecked 32-bit
half-resolution scaling and a strict signed 40-percent test before incrementing
feature `+0x148`; it also passes the intervals to `FUN_180072600` for `bb`
residual subtraction.

For each destination `(x,y)`, the two intervals are equivalent to requiring:

```text
0 <= x*t0 + y*t1 + t2 <= (source_columns - 1) * 256
0 <= x*t3 + y*t4 + t5 <= (source_rows - 1) * 256
```

`FUN_18005d9e0` supplies equal source/destination dimensions and passes the
result to `FUN_180072600`. In half-resolution mode it arithmetic-shifts only
translations `t2/t5`; linear terms remain unchanged.
