## Behavior

- Computes each raw ratio as rounded `source * 8192 / gain`, or
  `source << 13` when gain is zero, and writes the full u32 ratio plane supplied
  by the caller.
- Raw ratios and their full-frame sum use unsigned 32-bit arithmetic; the sum
  wraps modulo `2^32`. Mean rounding adds `pixel_count / 2` in 32 bits before
  unsigned division. Ratio rescaling uses the rounded runtime-base scale and a
  64-bit product before writing u32 caller output.
- When the optional application plane is present, the Gaussian source is u16
  `round(source * 8192 / round(gain * application / 8192))`; the zero-divisor
  fallback stores the low 16 bits of `source << 13`. Without that plane it is
  the low 16 bits of the raw ratio.
- Takes the rounded full-frame mean, derives
  `round(runtime_base * 8192 / mean)`, and rescales each ratio for the later
  calibration-map commit. Production profile 9 initializes the runtime base to
  8000 in `FUN_1800672e0`.
- Updates the auxiliary Q13 map only when the Gaussian-derived candidate is
  strictly within 328 of 8192. Its sample counter increments once per call and
  caps at 30.
- Dispatches selector 9 through `FUN_18007be70` at `0x180063c50`; the
  selector-specific kernel and backend contract are maintained in
  `FUN_18007be70.md`. The candidate is
  `round(adjusted * 8192 / gaussian)`, narrowed to u16 before the strict
  deviation gate. An admitted sample with entry counter `n` commits
  `(floor((n + 1) / 2) + old * n + candidate) / (n + 1)`.
- In profile-9 subtype-12 ownership, the first caller at `0x180067b46` supplies
  the persistent primary map and process-global counter. The second caller at
  `0x180067ba9` supplies the secondary map and a stack-local counter copy, so it
  cannot advance the process-global count.
