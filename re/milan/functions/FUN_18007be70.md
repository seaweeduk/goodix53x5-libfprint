## Extraction Selectors

In the extraction path, the numeric selector is a Gaussian filter ID resolved
through `FUN_18007d800`/`FUN_18007dd20`. `FUN_18004ac40` supplies IDs `0..5`
for the ordinary pass and `100..105` for the type-12 low-count retry.

After constructing an odd-length kernel on each axis, the dispatcher writes
context byte `+0x88` from `(selector - 6U & 0xfffffffd) == 0`. Thus the twelve
scale IDs select the weighted backends, while preblur ID `6` selects uniform
summation. The detailed state, reflection and arithmetic contracts are in
`FUN_18007d800.md`, `FUN_18007dd20.md` and `FUN_18004ac40.md`.

For same-sized nonnull word descriptors, the source and destination may be the
same descriptor. Both are temporarily marked type `0x42ff0002`, with byte stride
`2*width`, then restored to type `2`. The filter context owns its two copied
coefficient arrays, kernel objects, border-offset storage, row-pointer storage,
extended row and horizontal ring. These allocations are freed after execution;
the caller retains ownership of the image descriptors and pixel planes.
