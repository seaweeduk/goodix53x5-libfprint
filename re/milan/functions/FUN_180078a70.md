primary-pair output, configuration, sensor type, distance matrix, and layout

Profile-9 configuration is `[23,47,40,38,-1,16,246,1]`.

`FUN_18005e230` at `0x18005e28a..0x18005e2ad`; `FUN_18005a3c0` passes

only in the other arm. The type-12 reverse/fallback producer is

Setup at `0x180078b73..0x180078be0` and
`0x180078be5..0x180078c34` supplies exactly these half-open rectangles:

1. `[0,e_split) x [0,p_split)`.

The boundaries are not inferred from foreground or class bytes. Either axis
of either rectangle can be empty. Record classes, active state, masks and

the builder does not return a validation status.

## Reductions and publication

This invocation initializes two dwords per enrolled record to distance `192`
and two index dwords to `-1`. The two scans share those invocation-local
arrays but visit disjoint enrolled ranges. An empty target range therefore
retains `192,192/-1,-1`; no preceding feature comparison supplies its reductions.

`FUN_180076400` preserves ascending probe-index order within each enrolled row,
rejects ineligible descriptor cells, and updates best/second values strictly.
An equal best can become second when second was larger, while the earlier best
index remains selected. The one selector call at
`0x180078c39..0x180078c61` consumes the reductions in enrolled-index order.
It applies strict `best*40 < second*38`, target-coordinate collisions, and
capacity replacement as documented in [`FUN_180075a60`](FUN_180075a60.md).
All 42 output pairs are written, including the `-1,-1` tail.

The ordered primary pairs pass to the geometry fit in `FUN_18005a3c0` /
`FUN_18005b900`. The call at `0x18005a4fd` passes capacity 42, minimum 2,
and estimator argument 2; it scans all slots and ignores negative-index entries.
Descriptor selection and affine/orientation filtering are
separate boundaries: filtering can leave one or two pairs after a valid fit.
A subsequent alternate failure does not invalidate that primary result.

## Matrix ownership

Both scans borrow the same caller-owned `180x180` byte distance/layout matrices.
Only admitted cells in the two rectangles are written; rejected and
cross-partition cells retain caller defaults `0xff/0`. The matrices are not
feature fields or persistent caches. `FUN_180076850 -> FUN_180074ba0` consumes
distance cells, `FUN_180057900 -> FUN_180075220` consumes both matrices, and
`FUN_180079060` reduces distance cells into reverse candidates.
See [`FUN_180076400`](FUN_180076400.md),
[`FUN_180074ba0`](FUN_180074ba0.md), and
[`FUN_180075220`](FUN_180075220.md).
