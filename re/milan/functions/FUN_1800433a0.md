## Fixed Quality-Path Behavior

The production caller supplies a 25x25 patch and fixed-threshold mode. The leaf
first counts nonzero validity bytes and sums the prepared squared magnitudes.
Fewer than `625 / 2 = 312` valid bytes rejects the patch. Exactly 312 passes.

Fixed mode uses magnitude threshold 25. Magnitude equal to 25 is selected.
Fewer than `625 / 6 = 104` selected samples produces score zero but a valid
patch; exactly 104 proceeds. For selected samples it accumulates `gx^2`,
`gy^2`, and `gx*gy`, rounds each mean by adding `selected_count / 2` before
division, and computes:

```text
average_square = (mean_gx2 + mean_gy2) / 2
anisotropy_q16 = ((mean_gx2 * mean_gy2 - mean_cross^2) << 16) /
                 (average_square^2 + 1)
score_q16 = max(0, 0x10000 - max(0, anisotropy_q16))
```

The caller-provided patch-valid flag is set for both the selected-count-zero
score path and a computed score, but not for the fewer-than-312 path. Integer
division truncates toward zero. Fixed 8-bit input and 25x25 geometry keep the
signed-32 sums in range; the determinant arithmetic is signed 64-bit.

The selected-sample pass tests only `magnitude >= threshold`, not the mask a
second time (`0x180043540..0x180043561`). This is consistent with its producer:
`FUN_180044150` zeroes all three planes outside complete valid 3x3 neighborhoods,
and both threshold modes have a floor of 25. Valid-count admission nevertheless
counts every nonzero patch mask byte, including valid border pixels whose
prepared gradient remains zero.

All three means use the same positive half-count addition followed by signed
division (`0x1800435a1..0x1800435c5`). In particular the cross mean is
`trunc((sum_gxgy + floor(n/2))/n)` even when the sum is negative; it is not a
sign-symmetric nearest-integer operation. For byte inputs, each square and
absolute cross product is at most 65025; each 625-sample sum is at most
40640625 in absolute value. The determinant times 65536 is within signed
64-bit range. The quotient is narrowed to a signed dword before its lower
clamp (`0x1800435fe..0x180043617`).

That narrowing preserves the value for producer-built gradients. Writing the
rounded means as `a,b,c` and `t = floor((a+b)/2)`, the square-mean rounding
errors are at most one half. The positive half-count bias can increase a
positive cross mean by at most one half and cannot increase a negative cross
mean's absolute value. Together with `abs(mean(gx*gy)) <= mean(gx^2+gy^2)/2`,
this gives the conservative bound `abs(c) <= t+2`. The determinant is between
`-(t+2)^2` and `t*(t+1)`, so its divided Q16 result lies within
`[-327680,98304]`. The subsequent clamps publish only `0..65536`.
