## Behavior

This is an eight-neighbor binary thinning routine. It supports in-place use by
copying each pass to a temporary image. Two directional subpasses remove an
active interior pixel only when its eight-neighbor population is `2..6`, its
zero-to-nonzero transition count around the ordered ring is one, and the
subpass-specific cardinal-neighbor guards pass. Iteration stops when the second
subpass removes nothing or after `iteration_limit` rounds.

`FUN_18003ad10` passes a map containing only `0` and `2`, calls this function in
place with limit `100`, and treats every surviving nonzero byte as class `2`.

## Exact Subpasses and Lifetime

`0x18003b77c` initializes the first ring offset to `-columns`; the nine
consecutive dwords are north, northeast, east, southeast, south, southwest,
west, northwest, north. The repeated north closes the transition scan.
Population counts the final eight entries, so each of the eight neighbors is
counted exactly once. All byte predicates are zero versus nonzero.

With cardinal-neighbor booleans N/E/S/W, the first pass deletes only when
`!(N && E && S) && !(E && S && W)` in addition to the population and transition
rules. The second uses `!(N && E && W) && !(N && S && W)`. Each pass scans
rows `1..rows-2`, columns `1..columns-2`, reads an immutable snapshot taken
immediately before that pass, and writes only zero into the destination.
The second snapshot includes all first-pass deletions. Border bytes survive
unchanged; surviving active bytes retain their original values rather than
being normalized to 1.

If source and destination differ, the complete source is copied to destination
before iteration. Nonpositive iteration limits perform no deletion. The only
convergence flag is set by second-pass deletions (`0x18003b9a0`), tested at
`0x18003b9d5`; a first-pass-only change therefore still terminates that round.
The temporary allocation is freed on every ordinary return. Native allocation
results and dimensions are not validated.
