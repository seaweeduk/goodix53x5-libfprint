  and selects base metadata modes with strict 15%, 25%, 150, 300, 500, and 600
  boundaries.
- A separate severe predicate selects mode 9 and return status `0xc351` when
  class-3 count is strictly above 30% of the active count, or when the retained
  primary state is 2 and class-3 count is strictly above 10% of the active
  count. The classifier still writes the three auxiliary bytes and the caller
  continues through quality/coverage and selected-image publication.
- State flags returned by `FUN_18004ef70` can selectively promote mode 0 to 5
  and modes below 6 or 8.
- Promotion order is exact. Directional state `+0x0c == 2` raises any mode below
  8 to 8. Otherwise directional state 1 or secondary histogram state `+0x04`
  at least 1 raises any mode below 6 to 6. Primary state `+0x00 == 2` or
  directional state 2 then increments the secondary histogram state. Finally,
  secondary count state `+0x08 > 0` raises mode 0 to 5. All comparisons and
  mode stores are signed 32-bit; the context states are not truncated until the
  three auxiliary-byte stores.
- After mode promotion, it forms the extraction auxiliary tuple generically:

```text

aux[1] = selected_plane_entry
if primary_state == 2 || directional_state == 2:
    secondary_state += 1
aux[2] = secondary_state
```

  All assignments are low-byte truncations. The increment is an ordinary
  32-bit increment and occurs after mode decisions. Therefore primary state 2,
  selected-plane entry 0, and secondary state 0 produce `[2,0,1]` without a
  sample-specific branch. Exported `preprocessor` supplies entry 0 for ordinary
  WBF enrollment and identify calls and entry 2 only when exported argument 7
