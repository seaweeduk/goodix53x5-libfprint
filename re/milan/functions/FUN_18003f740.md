## Recovered Behavior

The helper consumes the 40-byte body of tag `96`, allocates one 28-byte live
record, zero-initializes it, and parses tags `e1,e4,e5,e6,e7,e8,e9` into the
seven record dwords. Tag `e3` is returned separately as the matrix slot. The
caller copies the record directly to `template+0x1b8 + e3*0x1c`.

The complete 45-byte wire order is `96/length=40`, then
`e3,e1,e4,e5,e6,e7,e8,e9`, each child followed by one little-endian dword.
Valid type-12 `e3` is a nonnegative slot; the seven record dwords are signed and
the encoder includes a relation exactly when the leading `e1` value is
nonnegative. See `../OUTER-TEMPLATE-CODEC.md`.

The serialized `e3` value is therefore a live triangular matrix slot, not a
feature index or evidence relation count. The helper does not reconstruct,
rank, invert, sort, deduplicate, or omit relations. Omission has already happened
in the encoder. Its caller writes repeated indices in encounter order, making
the last record the live value; natural type-12 writers never produce a
duplicate.

## Parsing And Failure Boundary

The caller has already consumed tag `96`; the input cursor initially points at
its length dword. The helper returns `0xffff0006` if fewer than four bytes
remain or the declared body exceeds the remaining input, and `0xffff0002` if
the 28-byte record allocation fails. It does not require length 40, require
each child exactly once, or enforce canonical child order. Recognized tags
consume a raw dword, repeated fields overwrite, and an unknown tag consumes
only its tag byte. Individual dword loads are not separately bounds-checked.
Successful parsing publishes the advanced cursor and the allocated record;
the outer decoder copies all seven words and frees that temporary allocation.

The helper does not validate `e3` against logical pair slots `1..1225`.
For canonical type-12 input, current `goodix_milan_template_unpack` in
`drivers/goodix53x5/milan/template/codec.c` copies the slot and seven words into
an inline relation array. `goodix_milan_relation_matrix_init` in `relations.c`
validates range, uniqueness, row bases and reference-star membership and maps
native slot `k` to current `slots[k-1]`. Persisted admission calls that initializer
from `goodix_milan_print_validate_template` in `print.c`.
