than `40`, this function calls `FUN_18003a3e0`. A successful comparison updates
each endpoint's pair score at `+0x1ab4`: stored `-1` is replaced directly;
otherwise `0x180041e8c..0x180041e93` and
`0x180041eb4..0x180041ebe` add the old and new scores as a wrapping dword and
divide the signed result by two with truncation toward zero. No other anti-fake
scalar is mutated here.

The comparison's success return is the only update gate. The returned score is
not tested for sign or against the `-1` sentinel, so a successful comparison
whose new score is `-1` still updates both endpoints. If an endpoint's old score
is also `-1`, replacement leaves it at `-1`; otherwise the wrapped sum includes
the new `-1` before signed division. For example, wrapped
`INT32_MAX + 1 == INT32_MIN`, whose signed halving stores `-1073741824`.
