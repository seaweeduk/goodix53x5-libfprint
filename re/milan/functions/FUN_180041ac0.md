## Recovered Behavior

For each prior feature, it calls `FUN_180078750` to obtain descriptor correspondences, copies matched Q8 coordinates, and estimates a six-word affine with `FUN_1800792d0`. Fewer than five raw or selected correspondences produce an unset identity relation. Otherwise it records the selected inlier count and transform only when the count, primary-detail and primary-coverage gates pass. Accepted direct relations append the prior feature index to an output candidate list before the optional anti-fake pair-score update.

The 42-slot temporary match arrays are initialized at `0x180041b65`; the pair
selector call is at `0x180041bac`, and affine estimation is at `0x180041cb1`.
The selector internally uses capacity 31; the larger caller arrays are storage,
not capacity.

## Registration Overlap Mode

`FUN_180042c30` supplies the three-word overlap mode `[context[3],0,0]` for
type 12; the half-resolution flag `context[3]` is one. The call at
`0x180041d5d` passes the new feature as source and the prior feature as target,
null primary/secondary score outputs, detail and coverage outputs, context count
zero, and null mismatch/masked-classification outputs. The return score is not
used for direct admission.

Consequently `FUN_180071d40` uses mode-zero scoring and never relatches detail
from the enhanced pass: its detail-replacement branch requires `mode[2] != 0`.
Both passes can affect its returned score, but direct admission consumes only
the primary high-bitmap detail and primary coverage. It does not compute a low
bitmap metric. See `FUN_180071d40.md` for the shared raster and pass lifetime.

Overlap runs only when the committed estimator mask has at least five nonzero
bytes; otherwise both detail and coverage stay zero. The final predicate is
`count > 10 || (count > 5 && detail > 215) ||
(count > 6 && detail > 208 && coverage > 64)`. Five inliers therefore always
leave the relation unset, even though they enter overlap computation. Neither
quality metadata nor the overlap return score replaces either of these inputs.

## Relation Evidence

For each prior feature, the helper writes one physical relation slot before
advancing to the next prior feature. An admitted relation stores its selected
inlier count and six-word transform, then appends that prior feature's index to
the graph-candidate list. An unadmitted relation retains the unset identity.
The slot write and candidate append are at `0x180041dbc..0x180041dfc`; relation
count advances once per prior feature through `0x180041efa`.

## Anti-Fake Pair-Score Ownership

For an admitted relation, both anti-fake pointers at feature `+0x160` must be
nonnull and both signed coverage dwords at feature `+0x120` (packed tag `b9`)
must be strictly greater than `40`. The comparisons are at
`0x180041e1e..0x180041e34`. Neither the primary feature-record count at `+0xf0`
nor the anti-fake object's record count supplies this gate. Thus a feature with
40 or fewer primary records can still take the pair comparison, provided its
actual admitted direct relation and coverage qualify.

The function then calls `FUN_18003a3e0`. A successful comparison updates
each endpoint's pair score at `+0x1ab4`: stored `-1` is replaced directly;
otherwise `0x180041e8c..0x180041e93` and
`0x180041eb4..0x180041ebe` add the old and new scores as a wrapping dword and
divide the signed result by two with truncation toward zero. No other anti-fake
scalar is mutated here.

The comparison's success return is the only update gate; there is no additional
sign or sentinel test on its output detail. `FUN_18003a3e0.md` establishes that
success means nonzero mutual pairs and a raw detail in `0..192`. A no-pair call
returns zero and leaves both endpoint scores unchanged. For producer-derived
endpoint state, stored `-1` is replaced by the successful detail; otherwise
signed halving of two values in `0..192` stays in that range without overflow.
The persisted `-1` sentinel is therefore distinct from raw no-pair detail zero
and is never a successful comparison's detail. The wrapping arithmetic above
still describes the instructions independently of these producer bounds.
