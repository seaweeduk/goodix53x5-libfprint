## Behavior

The function walks all payload bytes declared by the matrix header and sums a
256-entry byte popcount table. It returns zero when the total is below 20;
otherwise it returns the exact active-bit count. `FUN_18005d9e0` calls it before
and after each destructive interval removal, so their difference is the ordered
marginal area before optional half-resolution scaling.

## Storage And Arithmetic

The payload pointer is matrix offset `+0x18`; the signed payload byte length is
offset `+0x0c`. The loop at `0x1800475c0..0x1800475d8` uses two independent
dword sums for alternating bytes. The tail at `0x1800475da..0x1800475e3` includes
the final byte when the length is odd. The sums are combined before the signed
`CMP 0x14` / `CMOVL` at `0x1800475f8..0x1800475fc`.

The helper does not inspect geometric width or mask padding bits. Every declared
payload byte participates, including row padding; producers own the zero-padding
invariant. Header and payload are read-only. Empty payload returns zero.
