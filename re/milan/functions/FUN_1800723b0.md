## Profile-9/Type-12 Contract

`FUN_1800721a0` expands each 72-byte contiguous LSB-first packed mask from
`26x22` samples to a `52x44` byte matrix. The first matrix is source/probe and
the second is target/enrolled. For each active source coordinate `(x,y)`, the
helper computes:

```text

mapped_y = int32(ty_half + x*c + y*d + 0x80) >> 8
```

All products, additions, and row/column accumulators use signed low-dword
arithmetic. The right shifts are arithmetic. A source byte contributes only
when it is nonzero, both mapped coordinates are inside target `52x44`, and the
mapped target byte is nonzero.

For mode 1, each copied translation is halved by the native sequence
`INC; CDQ; SUB; SAR`. For every production affine other than the excluded
`INT32_MAX` wrap edge, this is signed C `(value + 1) / 2`, truncating toward
zero. This distinction matters for negative values: `-8248` becomes `-4123`,
while negative odd `-11101` becomes `-5550`.

The raw hit count is a signed dword. Profile mode 1 publishes four times that
count, using low-dword multiplication, but computes percentage from the raw
`52*44 = 2288` area:

```text

overlap       = int32((int32(raw_count << 8) + (2288 >> 1)) / 2288)
```

The signed division truncates toward zero. Reached counts are nonnegative and
far below every wrapping boundary, so this is ordinary half-up Q8 rounding.
Mode zero instead uses the generic `104x88` expansion, unhalved translations,
and unscaled count, but is not selected by this profile-9/type-12 caller.
