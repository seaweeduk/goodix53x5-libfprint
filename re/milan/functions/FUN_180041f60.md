## Recovered Behavior

The supplied active-candidate list must be nonempty. Selection starts with list
position zero and changes only when a later direct relation has a strictly
greater inlier count at `0x180041fd0..0x18004201f`. Equal counts retain the
first list entry. `FUN_180042840` builds the production active list in original
ascending candidate order, so production ties belong to the lowest physical
prior index. Selection is by strongest active direct relation, not by proximity
to the reference and not by relation-slot order.

Let `p` be the selected prior, `r` the raw context `+0x87d8` reference, and
`D` the stored direct current-to-`p` transform:

- `p > r`, `0x180042023..0x18004207d`: load the canonical stored `p`-to-`r`
  relation and call `FUN_180068860(stored, D, routed)`.
- `p < r`, `0x180042082..0x180042100`: load the canonical stored `r`-to-`p`
  relation, invert it through `FUN_1800689a0`, then call
  `FUN_180068860(inverse, D, routed)`.
- `p == r`, `0x180042102..0x180042115`: use `D` unchanged.

`FUN_180068860` composes its first transform after its second and normalizes the
linear four words after every composition. `FUN_1800689a0` does not normalize;
a wrapped-zero determinant copies its input unchanged. The routed six words are
stored in the canonical current/reference slot and copied to the caller output.
This is the same inversion, composition order, and normalization timing as
`goodix_milan_transform_route()` in current source.

The reference slot's leading word is independent of the routed transform. If
`p != r`, `0x18004211c..0x18004212a` changes a negative leading word to zero and
preserves every nonnegative value. If `p == r`, the direct slot is left wholly
unchanged. Thus routing through a non-reference active feature can materialize a
zero-leading reference edge, while an already admitted direct reference edge
retains its own inlier count.

Finally, `0x180042131..0x180042159` sets only the new feature active, copies the
routed transform to the caller, and adds
`0x100 + ((p & 0xff) << 8)` to `param_3[7]`. It does not change `r`, graph state,
or the selected prior's active word. The function has no status return or
rollback. It trusts the list, reference index, feature pointers, row bases, and
required stored anchor relation; invalid values can access outside the matrix.
