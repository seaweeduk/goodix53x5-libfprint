## Exact Algorithm

Given 256 nonnegative signed 32-bit histogram entries:

```text
sum = sum(hist[0..255])
q16[i] = (hist[i] << 16) / sum
total_p = sum(q16[i])
total_m = sum(q16[i] * i)
best_score = -1
best_bin = 255

for t in 0..254:
    left_p += q16[t]
    left_m += q16[t] * t
    if left_p == 0 or left_p == total_p:
        continue
    delta = left_m * 65536 / left_p
          - (total_m - left_m) * 65536 / (total_p - left_p)
    score = ((delta * delta) >> 16)
          * (((total_p - left_p) * left_p) >> 16)
    if score > best_score:
        best_score = score
        best_bin = t
return best_bin
```

Every division is signed integer division toward zero. Equal scores retain the
earlier threshold. The caller only invokes this helper with a positive
histogram sum.
