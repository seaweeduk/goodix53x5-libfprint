## Recovered Behavior

The function computes local residual roughness for one requested coordinate.
It first clamps `x` to `[1, columns-2]` and `y` to `[1, rows-2]`, then sums the
unsigned absolute differences between the clamped center and every value in its
3x3 neighborhood, including the zero center difference. It returns the signed
32-bit sum.

`FUN_18003a9b0` invokes it for the 3x3 set of requested centers around each
impulse candidate. This clamping belongs only to roughness evaluation. The
caller's later replacement-median loads are direct flat offsets around the
original candidate pointer and do not inherit the clamped center.
