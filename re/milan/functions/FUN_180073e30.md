## Recovered Behavior

The helper inverts the supplied Q8 affine, transforms each source record into the mapped feature's pixel frame with two signed rounding shifts, and looks up the mapped record index. It reports both in-bounds and matched counts and emits ordered `[source_index, mapped_index]` pairs for nonnegative map entries.

## Arithmetic And Mutation

`FUN_1800689a0` supplies the inverse `[a,b,tx,c,d,ty]`. Source record coordinates
`x,y` are unsigned 16-bit Q8. Each pixel lookup uses:

```text
pixel_x = signed32(low32((a*x+b*y+128)>>8)+tx+128)>>8
pixel_y = signed32(low32((c*x+d*y+128)>>8)+ty+128)>>8
```

Products/sums before the first shift are 64-bit; the translation and second
rounding addition are 32-bit. A record contributes to the in-bounds count only
when both pixel coordinates lie in the matrix's half-open dimensions. A signed
16-bit map entry below zero contributes no pair. No descriptor/orientation or
record-flag predicate is applied. Maps and records are read-only; emitted indexes
are relative to the supplied partition pointers. `FUN_180073ba0` owns rebasing.
