## Static Contract

- Computes the rounded positive-gradient average
  `(sum + positive_count / 2) / positive_count`, or zero for no positive
  gradients, then uses `average * 6 / 5` for decoded sensor type `0x0c`
  (profile 9 / sensor type 12). Gradient positivity is a signed-16 comparison;
  summation and division use signed dwords. The type-12 9,504-pixel geometry
  keeps the positive sum and rounding addition within signed-dword range.
- Reads retained global counter `DAT_1801dc9a0`. The per-pixel age threshold is
  `counter` for values zero through two, `counter - 1` above two, capped at two.
- Builds a byte candidate plane containing `0xff` only where
  `gradient_s16 > (int16_t) threshold` and the retained unsigned age byte is
  at least the low byte of the derived age threshold; all other bytes are zero.
  The comparison at `0x18004f6a0..0x18004f6a9` uses `CMP word,DX` / `JLE`
  followed by `CMP byte,R10B` / `JC`. This word comparison is distinct from
  the dword threshold comparison in the later age-mutation loop.
- Labels four-connected components through `FUN_1800807a0`, admits label 71,
  selects the three largest components strictly larger than 75 pixels through
  `FUN_1800802c0`, and writes class 1 only into previously unclassified pixels.
- Retained component ages and `DAT_1801dc9a0` are updated only under the gate at
  `0x18004f6cb..0x18004f734`. For selected-plane values 0/1, the exact gate is
  integer active-mask coverage `>= 75`. With 9,504 pixels this starts at 7,128
  active pixels. Coverage below 75 freezes both ages and count.
- The generic selected-plane value 2 preserves prior coverage in
  `DAT_1801dc9ac` and gates on prior coverage below 75. The ordinary exported
  profile-9/type-12 path resets the classifier input to 0 before every call;
  selector output 1 is not carried into the next classifier invocation. Input 2
  requires exported argument 7 equal to 1 and is not a normal WBF transition.
- When the gate executes, gradients strictly above `floor(mean * 6 / 5)`
  increment age up to five; gradients at or below `mean` decrement nonzero age;
  the interval between them is unchanged. The retained counter increments up to
  five.
- Candidate construction precedes current-call mutation. Its age threshold is
  count 0/1/2 for retained count 0/1/2, and two for retained counts 3 through 5.
- The retained counter and per-pixel age plane can be imported on the first
  type-12 call from the packet at workspace `+0x26488`; that packet is included
  in official calibration save/load through the aliased `DAT_18023faf8` block.
  A valid imported count of five therefore uses age threshold two before any
  current-call age mutation. Default calibration clears the packet, leaving
  count and ages zero and selecting age threshold zero.

## Component Labeling And Selection

The call at `0x18004f7c6` passes the candidate plane, rows, columns, a temporary
signed-dword label plane, a zeroed 100-dword size table, and the four-dword
configuration `[4, 0, 0, 70]` from `0x1800e02f0` to `FUN_1800807a0`
(`0x1800807a0..0x180080ba9`). The configuration fields are connectivity,
horizontal margin, vertical margin, and label-limit parameter. Both margins
are zero here; candidate construction, not this helper, limits valid support.

- Initializes every label to `-1`. Seeds are visited in increasing row-major
  order. An unvisited zero candidate becomes label zero. A nonzero seed starts
  the next positive label, beginning at one.
- Floods through four neighbors in the order left, up, right, down. Bounds
  comparisons are signed; row and column bounds exclude wraparound and
  diagonals. Each neighbor is considered only while its label is `-1`.
- Labels and counts a nonzero seed or neighbor when discovered, before queue
  processing. Previously classified pixels are not excluded from candidate
  topology or component sizes: the class plane is not an input to labeling.
- Uses a FIFO ring of `0x992` (2,450) coordinate pairs. Offsets `+0x4c90`,
  `+0x4c94`, and `+0x4c98` hold occupancy, head, and tail. `FUN_180080f70`
  peeks the head; the caller advances it. A neighbor is still labeled and
  counted if the FIFO is full, but is not enqueued (`0x180080a5b..0x180080a74`).
  Each pixel can be enqueued only once because discovery changes its label
  from `-1`. A component containing at most 2,450 candidate pixels therefore
  cannot encounter enqueue rejection, independently of its shape.
  Each component permits 19,601 dequeue iterations, with the guard at
  `0x1800809a0..0x1800809ad`; this iteration limit exceeds the entire type-12
  pixel count.
- The ring is initialized once per labeling call (`0x180080876..0x18008087d`),
  not once per component. Head and tail wrap independently at 2,450. The head
  item is read while occupancy is positive, then removed and occupancy reduced
  (`0x1800809b8..0x1800809e8`) **before** examining its neighbors. Thus capacity
  limits pending discoveries, not cumulative component size or total enqueues.
  On type 12, discovery-once bounds all dequeues by 9,504, so the iteration
  guard cannot leave queued work at a component boundary. Each new component
  starts with occupancy zero and equal head/tail indices, which need not be zero.
- Before any rejected enqueue, the pending items form the ordinary FIFO
  breadth-first frontier: a suffix of distance layer `d` followed by the
  discovered prefix of layer `d+1`. During a neighbor loop this statement uses
  the already-popped vertex's distance. Bounding a single layer, total
  enqueues, or the number of positive gradients alone is not the same as
  bounding this mixed-layer frontier.
- A sufficient shape-independent bound is 3,676 candidate pixels per connected
  component. Its row-major seed has at most two candidate neighbors (none above
  or to its left); each later popped vertex has a discovered parent and can add
  at most three new neighbors. After `p >= 1` pops, pending occupancy `q` is at
  most `2*p`, including partial neighbor scans. Also `p+q <= component_size`.
  An unbounded traversal would therefore need at least 1,226 popped plus 2,451
  pending distinct pixels, or 3,677 pixels, to reject its first enqueue in the
  native ring. This degree-only argument does not constrain larger components.
- After finishing each component, increments the next label and stops when
  it exceeds `limit + 1` (`0x180080ae4..0x180080af6`). With limit 70 this
  completes label 71 and returns 71, not 70. It stops scanning immediately;
  untouched labels remain `-1`. The return value is the final positive label,
  or zero for an empty candidate plane. The invalid connectivity/null-plane
  guard returns `-1`; this caller supplies connectivity four and allocated
  planes.

The call at `0x18004f7fd` invokes `FUN_1800802c0`
(`0x1800802c0..0x1800803c7`) with the size table, returned label count, three
output slots prefilled with `-2`, slot count three, and minimum size 75.
For each slot it scans table indices zero through the returned label count
inclusive. A signed strict-greater comparison at `0x180080342..0x180080345`
updates the winner. Thus size 75 is excluded, size 76 is eligible, and equal
sizes retain the earliest label, hence the earliest row-major seed. Index zero
stays zero and cannot win. A slot without an eligible component retains `-2`.
Each selected size is temporarily zeroed before the next scan; the helper
restores all selected sizes before returning (`0x180080398..0x1800803b0`).

At `0x18004f810..0x18004f839`, a pixel becomes class one exactly when its
existing class byte is zero and its label equals one of the three slots.
Existing classes 1, 2, and 3 are preserved. Background label zero, unvisited
label `-1`, and absent-slot sentinel `-2` cannot select one another. The size
table, candidate plane, and labels do not escape the owner and have no consumer
after these class writes.

## Producer And Consumers

The gradient argument is the separate plane produced by `FUN_180051bd0` at
`0x18004d74e` and passed at `0x18004d9f0..0x18004d9fd`. It contains zero or the
largest positive signed-16 difference to a valid eight-neighbor sample of the
filtered prepared image. Unmasked pixels receive zero. The producer initializes
each gradient to zero (`0x180051cf9`), subtracts in 16 bits
(`0x180051d64`), and replaces the maximum only on signed strict improvement
(`0x180051d70..0x180051d7a`); outputs therefore lie in `0..32767`. Dimensions
for profile 9 are 88 rows and 108 columns, from the seven-field row at
`0x1800e46b4` described in `ppp_param_init.md`.
Neither component selection nor class publication mutates the gradient plane.

On the ordinary initialized profile-9 producer, `FUN_180069820` clamps both
setup and live samples to `0..4095`. `FUN_18006d540` passes its normalized raw
copy to `FUN_18006b290`; the latter preserves the incoming RCX live pointer
and RDX generation-workspace pointer through its call at `0x18006b328` to
`FUN_18004ef70`. `FUN_1800508a0` supplies that live pointer and workspace
`+0x9924` to `FUN_18004ee80`. This primary input is separate from the
gain-derived working frame at workspace `+0x13244`.
Profile 9 clears packed bit 1, so
`FUN_180064bb0` seeds the setup plane at workspace `+0x9924` with normalized
setup plus 7095, in `7095..11190`. `FUN_18004ee80` therefore does not take its
`setup[0] < 4096` offset branch: its prepared plane is in `3000..11190`.
The primary separable filter's selector 10 constructs the nonnegative Q16
kernel `[6980, 51576, 6980]`, whose coefficients sum to 65536.
`FUN_18007d9c0` truncates the horizontal unsigned-dword sum by shifting 16;
`FUN_18007d260` uses vertical bias zero and shift 16. Each pass's accumulator

nor output-word narrowing overflows. Both passes preserve the interval.

candidate comparison

This range is preserved across the initialized retained-state lifecycle.
`preprocessor_init` (`0x1800027b0`) clears ready global `DAT_180249afc` before
calling `FUN_18006d540`, forcing its setup branch even after a successful
calibration load. That branch normalizes the current setup frame and replaces
workspace `+0x9924` through `FUN_180064bb0` before setting ready. A failed setup
leaves ready clear; exported `preprocessor` admits live processing only when
ready is one. A loaded setup plane is therefore not the live classifier's
source. Normal and nested gain updates copy setup/live into separate
temporary/scaled planes; their generation-workspace calibration writes target
`+0x04` and its sample count, while rendered working words target `+0x13244`.
They do not replace the primary setup/live operands. The intervening retained
reference updater `FUN_1800512c0` reads the prepared plane into a separate
temporary and updates reference/support-age/count and coverage-control state
without writing the prepared input. After gradient construction, `FUN_180052b80` and
`FUN_1800514e0` read that gradient and write separate score planes; their path
sums do not replace the gradient passed to component labeling. Retained
reference and component-age import/update change neither primary operand.
Any retained age/counter state can only remove vertices through the
additional candidate predicate after the gradient comparison; it cannot evade
the range or threshold-population bounds. See `preprocess_load_calidata.md`
for load/setup ordering and `FUN_1800668f0.md` for normal/nested gain ownership.

The nonnegative threshold confines candidates to the eroded support described
in `FUN_18004dd10.md`, at most `72 * 92 = 6624` pixels. Let `P` be the number
of positive gradients, `S` their sum, `A` their rounded mean, and
`T = floor(6*A/5)`. For `P > 0`, `A >= 1`, `T >= 1`, and
`S <= P*A + ceil(P/2) - 1`. If `K` gradients exceed `T`, then
`S >= P + K*T`, hence

```text
K*T <= P*(A-1) + ceil(P/2) - 1 < P*(A-1/2).
```

Writing `A = 5*m+r`, `0 <= r <= 4`, gives
`7*T - (8*A-4) = 2*m+4-r >= 0`. Therefore `K < 7*P/8`, and the whole
candidate plane contains at most 5795 pixels. The age predicate can only
remove candidates. With no positive gradient the candidate plane is empty.
This population bound is not a pending-FIFO bound.

The candidate plane is fixed before the age-mutation loop. That loop completes
before labeling and reads only gradients, ages, mean/threshold, and the coverage
gate (`0x18004f6cb..0x18004f734`). FIFO occupancy, labels, and selected component
sizes cannot affect this invocation's retained ages or counter. A queue-induced
classification difference, if present, must propagate through the class-plane
consumers rather than through a direct change to the component age update.

`FUN_18004d510` applies its class-2 mask at `0x18004d960..0x18004d97a` before
calling this owner. The mask producer pair `FUN_1800514e0` / `FUN_180051af0`
reads the filtered image, valid mask, gradient, and direction planes, not the
class plane or component ages. A selected class-2 pixel overwrites any class
byte below three. Component class one has lower precedence: it fills only a
remaining zero. Existing severe class three wins over both.

After the component call, `FUN_18004d510` consumes all nonzero class bytes in
its strict `classified_count * 100 > active_count * 30` primary-state override
and optional decision-plane rebuilding (`0x18004da20..0x18004daa5`). This
does not clear or otherwise rewrite the class plane. `FUN_1800508a0` then
performs conditional temporal class-three publication and the interior
low-live-value class-three overwrite; these can replace individual class-one
pixels, but are not an unconditional clearing of component output.

Finally, `FUN_18006b290` counts class bytes and clears classes one and two from
the outgoing mask at `0x18006b350..0x18006b378`. Their counts are already retained
in registers and participate in metadata-mode selection, so clearing the bytes
does not discard the classification result. The primary-state override also
feeds that owner's auxiliary-byte and severe-status decisions. Its caller
`FUN_18006d540` passes the chosen mode and mask to metadata encoding through
`FUN_180070fc0` at `0x18006dd34`. See `FUN_18004d510.md` and
`FUN_18006b290.md` for those complete output contracts.
