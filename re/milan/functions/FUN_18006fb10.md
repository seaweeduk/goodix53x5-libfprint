## Recovered Behavior

It validates the alternating even-zero/odd-one marker over the first-row prefix,
decodes the two-bit low mode and three-bit high mode from the final eight pixels,
and, when the mask-present bit is set, allocates a byte mask. The first row is
forced valid and subsequent pixels are copied from image LSBs.

For width108 the prefix is columns0..99. Let `a,b` be the low bits at
columns100,101. The image pair `00,10,11,01` maps to packed low values
`0,1,2,3`, respectively; this is not the direct binary value `a+2*b`.
Columns103..105 form the ordinary little-endian three-bit high value, shifted
left8 in the packed result. Column102 is the independent mask marker.
Columns106,107 do not contribute to decoding. An invalid prefix returns zero
without writing either output; callers must initialize their packed scalar
and mask pointer. A valid prefix always writes the packed scalar, even when
the marker is absent and the return value remains zero.

A valid prefix without the mask-present bit returns zero and allocates nothing;
a valid prefix with the bit set returns one after allocating exactly
`width * height` bytes. Thus the return value used by `FUN_18004ae70` is a
mask-availability result, not merely prefix validity. Mask polarity is
`1 = usable`, `0 = broken`: on first mask initialization the producer
`FUN_180070fc0` stores whether its supplied exclusion byte is zero. That input
is the residual plane in the first metadata pass and surviving class3 plane
in the classifier pass; an existing mask is intersected rather than replaced.

Ownership is closed on the only caller. `FUN_18004ae70` initializes the output
pointer to null, calls this decoder at `0x18004aef8`, and, only on return one,
passes the allocation to `FUN_18004db10` before freeing it at `0x18004b603`.
There is no intervening caller exit.

Mask-present input is a reachable profile-9/type-12 preprocessor product. The
live path calls `FUN_18006b290` at `0x18006dd00`; its apply-mask output reaches
`FUN_180070fc0` at `0x18006dd34`. The resulting filter contract is maintained in
`FUN_18004db10.md`.

The mask allocation is used without a null check before initialization; this
function has no recoverable allocation-failure result distinct from mask
absence. The source image is read-only and the returned dense mask has a
separate lifetime. Multiple encoder passes intersect their usable pixels;
see `FUN_180070fc0` for initialization versus existing-marker behavior.
