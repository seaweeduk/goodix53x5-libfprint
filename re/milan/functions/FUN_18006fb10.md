## Recovered Behavior

It validates the alternating even-zero/odd-one marker over the first-row prefix,
decodes the two-bit low mode and three-bit high mode from the final eight pixels,
and, when the mask-present bit is set, allocates a byte mask. The first row is
forced valid and subsequent pixels are copied from image LSBs.

A valid prefix without the mask-present bit returns zero and allocates nothing;
a valid prefix with the bit set returns one after allocating exactly
`width * height` bytes. Thus the return value used by `FUN_18004ae70` is a
mask-availability result, not merely prefix validity. Mask polarity is
`1 = usable`, `0 = broken`: the producer `FUN_180070fc0` stores the inverse of
its surviving class-3 plane in the image LSBs.

Ownership is closed on the only caller. `FUN_18004ae70` initializes the output
pointer to null, calls this decoder at `0x18004aef8`, and, only on return one,
passes the allocation to `FUN_18004db10` before freeing it at `0x18004b603`.
There is no intervening caller exit.

The authoritative `142/1` processed image has a valid mode prefix but its mask-
present marker is clear. `FUN_18004ae70` therefore does not invoke
`FUN_18004db10` for this row.

live path calls `FUN_18006b290` at `0x18006dd00`; its apply-mask output reaches
`FUN_180070fc0` at `0x18006dd34`. Production evidence and the resulting filter
contract are maintained in `FUN_18004db10.md`.
