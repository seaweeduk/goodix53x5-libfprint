## Behavior

The function requires a nonnull adapter-status output and clears it. If the
global enrollment session exists, it calls `enrolFinish` and clears the global.
If the global completed packed record exists, it frees the record, clears its
pointer, and resets its size to zero. It always returns zero and ignores the
`enrolFinish` result.

`FUN_18002d4b0` invokes this whole-session cleanup when `enrolAddImage` returns
`0x83`; ordinary bad-capture rollback uses `enrolDeleteImage` instead and keeps
the session alive.
