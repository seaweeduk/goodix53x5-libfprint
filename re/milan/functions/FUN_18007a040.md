## Contract

The first argument is the live template. The second optionally supplies one
28-byte edge per live feature for an external vertex at index `feature_count`.
Enrollment always passes null, so only the `feature_count` real vertices are
relevant here. There is no maximum-count, graph-reference, or graph-established
validation inside the helper.

For each real feature as a root, the function performs a worklist traversal over
strictly positive relation ranks. Rank zero is defined but is not traversable;
negative ranks are unset. Roots are processed in ascending physical order. Each
root resets a 51-entry visited/admission vector to `-1`, marks the root, and
uses a LIFO worklist. Every popped vertex scans unvisited candidates in
descending physical order, so the lowest newly admitted candidate is processed
next. The vector is only an admission marker: discovered entries receive the
root index, not their predecessor. The 51-by-51 signed quality matrix is instead
zeroed once for the whole call and retained across roots.

On every non-root pop, native reloads the visible root/current slot rank and
transform. It writes that visible rank into both symmetric quality cells before
scanning candidates. Thus a synthesized root/current edge contributes visible
rank two to the next hop; native does not carry its separately published
bottleneck quality forward as a general widest-path value. For each newly
discovered candidate, native writes the direct current/candidate rank into both
symmetric quality cells and computes `min(visible_root_current_rank,
direct_edge_rank)`. Canonical triangular transforms are inverted as needed
through `FUN_1800689a0`: the root/current edge is oriented `current -> root`,
the current/candidate edge is oriented `candidate -> current`, and
`FUN_180068860(current_to_root, candidate_to_current)` produces
`candidate -> root`, including that helper's fixed-point normalization. The
result is stored directly when the candidate is above the root and inverted
when it is below the root.

The assembly publication gate accepts a root/candidate rank below two, or rank
two only when the newly computed quality is strictly greater than the retained
quality cell. Publication stores the composed transform and visible rank two;
direct ranks above two are never replaced. In null-external real-vertex mode,
the visited rule narrows the reachable behavior: an initial positive root edge,
including rank one or two, claims its candidate during the root scan and cannot
be revisited through an equal or stronger alternate path. Consequently rank
zero or negative pairs can be synthesized, rank-one pairs remain direct, and a
rank-two edge synthesized early or inherited from an earlier root keeps its
first transform. The rank-two strict-improvement branch exists in assembly but
was not reachable in adversarial null-external controls. Quality cells leaking
across roots therefore did not affect a real-vertex replacement decision.

Active-state propagation is narrower than ordinary graph connectivity. It runs
only when a rank-two edge is created or improved between two real features. If
either endpoint's `b5/+0x110` equals exactly one, both endpoints are set to one.
A positive direct edge by itself does not propagate `b5`, and inactive vertices
can therefore remain inactive despite belonging to a directly connected
component. No other feature scalar is written.

The return is zero when no real-feature synthesized edge is published and one
when at least one is published. Callers in scope ignore it. The only persistent
mutations are relation rank/transform words and the conditional exact-one `b5`
writes. Feature count, relation cardinality `+0x24`, `f2/f3/f4/f5`, order, queue,
tail state, records, anti-fake data, and `bb` are untouched.

## Enrollment Boundary And Packing

`FUN_180042c30` calls this helper with a null external edge only after insertion
makes live count equal configured physical maximum: 40 for profile 9/type 12.
It runs immediately before `FUN_180047550`. Requested enrollment completion does
not imply this call.

Packing is a later reference-star projection. A synthesized edge is visible only
if closure makes it a nonnegative relation incident to `f2`; synthesized edges
elsewhere remain live-only. A graphless 40-feature state has no positive edge,
so closure returns zero and changes no relation, active flag, metadata, order, or
tail. In a sparse established control with direct edges `0-1` rank 5 and `1-2`
rank 4, closure creates slot 2 as
`[2,256,0,300,0,256,30]` and activates feature 2 when feature 0 is active. It
does not activate feature 1 merely because direct slot 1 connects it to feature
0. A disconnected direct `3-4` component is unchanged.

Naturally reconstructed all-connected and established-partial 40-feature
controls required no closure writes: every usable path already had a direct
edge. That does not make this call removable; the sparse state proves generic
rank, transform, active, packed-size, and return-value visibility.

orientation at `0x18007a501..0x18007a5f5`, whole-call quality initialization at
`0x18007a0a6..0x18007a0fd`, per-root visited reset at

## Current Source Status

Current `drivers/goodix53x5/milan/relations.c` has no equivalent full-matrix
closure, and `goodix_match_combine_templates()` projects the reference star
without invoking one. Source therefore models the pre-closure relation state at
the synthetic-valid 40-feature boundary. An equivalent implementation must
preserve the traversal, visible-rank-two publication, transform composition,
and synthesized-edge-only active propagation defined above; this gap does not
affect normal 12-stage production enrollment because it remains below physical
capacity.
