## Recovered Behavior

It loads three Q8 point pairs and solves destination from source. Source
coordinate subtraction is wrapping dword arithmetic followed by signed extension.
Each destination coordinate is first shifted left by ten as a dword; subsequent
destination subtraction therefore also wraps before signed extension. Products,
determinants, and numerators are signed 64-bit. Nonzero determinants use signed
`IDIV`, hence quotient truncation toward zero. Each quotient is narrowed to its
low signed dword before the linear coefficient is arithmetic-shifted right by
two, producing Q8 `[a,b,tx,c,d,ty]`.

The first translation uses destination point 0 and the second uses point 2.
Each subtracts the narrowed pre-`>>2` Q10 coefficients times the corresponding
source coordinate from the wrapped Q10 destination coordinate, then applies a
signed 64-bit `>>10` and narrows to dword. A zero determinant substitutes
`INT32_MAX` independently for both row coefficients and still computes the
translation; it does not return failure. The result is therefore an
`INT32_MAX`-derived affine, not identity, zero, or a status value.

Evidence is the determinant and first row at `0x1800684bd..0x180068576`, followed by the second row through `0x18006864c`.

- Type-12 unresolved behavior: none. Degenerate determinants produce the
