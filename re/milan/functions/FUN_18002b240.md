# FUN_18002b240

## Audit Scope

Production adapter caller of `ppp_param_init` at `0x180002710`. This note was
created before first Ghidra inspection during the independent methodology audit.

## Questions

- Which engine-context field supplies the sensor type?
- Does the adapter transform or constrain that value before the export call?

## Audit Findings

- The caller receives `uint32_t *sensor_type` as its third argument and passes
  `*sensor_type` directly to `ppp_param_init` without transformation.
- It stores the same value in global `0x1800f2408` and uses it to index the
  adapter's row/column table.
- It also passes the value to `FUN_180030040`, which returns `1` for type 9 and
  controls the production enrollment-preprocessing branch.
