## Recovered Behavior

The function builds a 256-entry signed 32-bit histogram from source bytes whose
parallel mask byte is nonzero. Selector zero, used for the profile-9 enhanced
bitmap, sets target `(205 * active_count + 128) >> 8`; nonzero selector uses
`50` instead of `205`.

It scans values `1..255`, adding each preceding bin into the current bin. At the
first cumulative value at least the target, it returns the current value when
`cumulative - target <= target - previous_cumulative`, so an exact distance tie
chooses the upper value. Otherwise it returns the preceding value. With no
active samples, target and cumulative counts are zero and the first iteration
returns `1`. The scan's exhausted fallback returns byte zero.

Current `goodix_milan_feature_enhanced_bitmap()` reproduces selector-zero
semantics at `drivers/goodix53x5/milan/feature/enhancement.c:316-358`.
