## Recovered Behavior

The function builds a 256-entry signed 32-bit histogram from source bytes whose
parallel mask byte is nonzero. Selector zero, used for the profile-9 enhanced
bitmap, sets target `(205 * active_count + 128) >> 8`; nonzero selector uses
`50` instead of `205`.

It scans values `1..255`, adding each preceding bin into the current bin. At the
first cumulative value at least the target, it returns the current value when
`cumulative - target <= target - previous_cumulative`, so an exact distance tie
chooses the upper value. Otherwise it returns the preceding value. With no
active samples, target and cumulative counts are zero and the first iteration
returns `1`. The scan's exhausted fallback returns byte zero.

The target uses a logical right shift of the 32-bit product plus `128`.
Both the cumulative admission (`0x180071315..0x180071318`) and distance
comparison (`0x18007132d..0x180071339`) are signed 32-bit comparisons. In
particular, when bin zero already exceeds the target, the first iteration has
`target - previous_cumulative < 0` and returns `0`, not `1`. If bin zero equals
the target, bin one empty selects `1` (a distance tie); bin one nonempty selects
`0`. This distinction applies even though all histogram counts are nonnegative.

For the type-12 `52x44` matrix, active count is in `0..2288`, target is in
`0..1832`, and counts, products and signed differences fit in 32 bits. For every
nonempty mask, target is positive and at most active count, so the scan reaches
a cumulative count at least target by bin 255. Empty support selects `1`.

## Inputs And Ownership

The source matrix supplies signed byte count at `+0x0c` and byte data pointer
at `+0x18`; the mask supplies its data pointer at `+0x18`. The function scans the
source byte count linearly and assumes a parallel mask of sufficient length.
Mask values are admitted by nonzero testing, without a binary-value restriction.
It only reads both inputs; the histogram is stack-local and the selected value
is returned in the low byte. The type-12 caller supplies compact even/even
projections of enhanced image and mask; see [FUN_18006fef0](FUN_18006fef0.md).

`drivers/goodix53x5/milan/feature/enhancement.c`.
