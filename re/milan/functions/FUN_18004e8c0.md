## Exact Behavior

This path is entered only when retained reference count is greater than 20. Its
source is the 88x108 retained `profile9_history_reference`. Its byte mask is
zero at the outer three rows/columns and one elsewhere only when both the
eroded-valid mask is nonzero and:

```text
profile9_reference_age[i] * 100 >= profile9_history_count * 50
```

It first calls `FUN_18004ef90(source, qualified_mask, 9504, ..., 9000, ...)` and
writes the resulting 0/1 state to classifier context `+0x04`.

The separate threshold output from that call is passed as both the start
threshold and current-source floor to `FUN_180052b80`
(`0x18004ea46..0x18004ea67`). It is derived from the original masked histogram,
not its clipped copy used for the 0/1 state. The first cumulative bins reaching
35% and 50% of the original histogram weight give values
`t35 = minimum + (range * bin35 + 128) / 255` and similarly `t50`.
Use `t50` only when `t50 - t35 > 500`; otherwise use `t35`, then cap at 9000.
There is no histogram-mode cap on this threshold. A nonpositive signed-16
range returns the signed minimum as threshold before this cap.

`FUN_18004ef90` initializes signed minimum to 32767 and maximum to zero, then
updates them only for nonzero mask bytes. It subtracts minimum from maximum in
a word and tests that word as signed (`0x18004f030..0x18004f058`). If nonpositive,
it writes minimum, returns `0x80000003`, and leaves the separate histogram-state
output untouched (`0x18004f05a..0x18004f065`). Thus an empty mask yields 32767;
a nonnegative constant plane yields its constant, even above 9000. Neither
case reaches the ceiling. The caller initializes the histogram-state output to
zero and continues with the threshold despite this return status. For a positive
signed range, the ceiling uses a signed comparison against the caller's 9000
argument after percentile-gap selection (`0x18004f2b1..0x18004f2c3`).

It then uses `FUN_180051bd0`, `FUN_180052b80`, and `FUN_180051160` with temporal
configuration `[1600,768,384,0,700,800]` and score mode zero. Every nonzero
adaptive-mask byte assigns class 3 to context `+0x20`'s class plane; zero bytes
leave existing classes unchanged (`0x18004ea98..0x18004eaac`). This is assignment,
not a bitwise OR. The current counterpart is `milan_profile9_temporal_class3()`.

Finally, `FUN_1800514e0` and `FUN_180051af0` with configuration `[400,512]`
form a separate strict score mask. Its count writes context `+0x08` as 2 above
600, 1 above 300, and 0 otherwise.
- The `+0x08` count state does not become one of the three auxiliary bytes, but
  a nonzero value suppresses the fallback replacement of a zero `+0x04` state.

`FUN_180051af0` reads these score words as signed. It averages only
`0 < s16(score) < 400`, with `(sum + count/2) / count`, then selects
`max(2*average,400)` as the threshold. With no averaging samples the threshold
stays zero. After clearing the whole destination, it writes `0xff` only for
`s16(score) > threshold` (`0x180051b90..0x180051b99`). A word with its high bit
set never qualifies; it is not a large positive score. The same scalar-mask
contract serves the calibration-plane fallback `FUN_18004dea0`. Neither
strict-mask call mutates the retained reference or the temporal class plane.

The score producer does not clamp to a nonnegative signed-word range.
`FUN_180051bd0` subtracts neighboring source words in 16 bits and retains the
strictly largest positive signed-word difference, with first-direction tie
ownership. `FUN_1800514e0` follows at most four of those directions, adds each
gradient in 16 bits, and stops at a negative direction index. This caller uses
start ceiling `0xffff`, so every signed source word at a qualified pixel passes
that ceiling. The stored score is the low word of the path sum, equivalently
the start-minus-terminal source difference modulo 65,536. No local guard
excludes a high-bit score. If all source values are nonnegative signed words,
each chosen edge is an ordinary decrease and telescoping bounds the score by
32,767; that bound does not follow merely from the signed-word input type or
from the importer, which accepts negative reference words. See
`FUN_1800501d0.md` and `FUN_1800512c0.md` for the reference producer.

An importer-representable boundary follows from a row-constant coarse reference
with plateaus `3*d` and `-3*d`, joined by the coarse words `[3*d,d,-d,-3*d]`.
Away from the image edges, reconstruction gives the seven-column descent
`[3*d,2*d,d,0,-d,-2*d,-3*d]`. Qualified horizontal neighbors select the rightward
direction before equal diagonal alternatives. The six nonzero four-step score
words per qualified row are `[4*d,4*d,4*d,3*d,2*d,d]`; the remaining plateau
pixels have zero scores. For `d=8192`, the first three words are `0x8000` and
only the last three enter the strict mask. For `d=8191`, all six enter it. Neither
value supplies an averaging sample below 400, so the strict threshold is zero.
With `R` qualified rows, `51 <= R <= 72`, these are respectively `3*R <= 300`
and `300 < 6*R <= 600`, yielding secondary count states zero and one.

These reference/support inputs do not require an out-of-range packet field:
all coarse reference words are signed words, reference count may be 50, and
support age 50 inside the row band and zero outside is accepted independently
of the reference values. An admitted zero-mean reference update preserves the
entire reference, saturates the count and inside ages at 50, and raises outside
ages only to one; qualification therefore preserves that band. A constant
type-12 setup workspace value 7196 and normalized-live value 3196 gives prepared
delta 4000 through `FUN_18004ee80`, hence that zero-mean update. The setup value
is normalized setup sample 101 plus 7095. Both constant raw frames satisfy
`FUN_1800695e0`'s strict `100 < sample < 3800` predicate at every tested pixel,
passing the setup 85% and live 15% admission gates. Constant setup sample 100
would fail the setup gate. The ordinary contrast-mask producer admits the
101/3196 pair, and an interior transition and row band survive its eight-pixel
erosion.

For this descent, the signed histogram range is nonpositive and its state stays
zero. The temporal path cannot enter a negative destination; its positive scores
are at least `d`, so its below-800 averaging population is empty and it adds no
class-three pixels. With constant primary input, zero component ages, and a
constant nonnegative calibration plane, the primary/class/directional outputs
are also zero. At `d=8192`, the zero secondary states permit the unseeded
calibration fallback, which returns zero states again; at `d=8191`, count state
one suppresses that fallback. `FUN_18006b290` consequently publishes mode zero
or mode five, respectively, with status zero, mask-application zero, zero class
and auxiliary planes, and the same reference/support snapshot rules. This count
state is therefore consumed by metadata publication, not merely retained as a
diagnostic count. See `FUN_18006b290.md` for the exact promotion order.

## Class-Plane Lifetime

The adaptive mask and score/gradient/direction planes are temporary allocations
freed before return. The class plane belongs to the caller. The later strict
score pass reuses the temporary score and mask planes, not the class plane.
Its scalar output and any secondary-state fallback do not remove temporal
class-3 assignments. In `FUN_1800508a0`, the subsequent interior low-intensity
pass preserves existing class 3 and can add further class-3 pixels
(`0x180050de0..0x180050df6`). The subtype-11-only postpass at `0x180050e12` is
not used for profile 9. Flood mechanics are documented in
[`FUN_180051160.md`](FUN_180051160.md).

The outer `FUN_18006b290` consumer counts classes 1, 2, and 3 and clears only
classes 1 and 2 from the render mask (`0x18006b350..0x18006b378`). Class-3
coverage contributes to its mode, mask-application, and classification-retry
outputs; temporal assignments are not merely internal scratch state. See
[`FUN_18006b290.md`](FUN_18006b290.md) for that publication contract.
