## Behavior

The helper initializes a temporary plane to `0xff`, scans the complete input,
and changes a temporary byte to zero exactly when the image byte is `0xff`.
`0xfe` and every other byte remain valid. If no `0xff` byte was found, it fills
the complete output mask with `0xff`. Otherwise it dilates the temporary valid
plane once through `FUN_180073ff0`.

The output is therefore `0xff` exactly when the center or an in-bounds
horizontal/vertical neighbor at distance one or two is not `0xff` in the input.
It is zero only when every in-bounds member of that nine-position cross is
`0xff`. Out-of-plane positions are ignored, so an isolated valid interior pixel
produces nine admitted bytes while a valid corner produces five. An all-`0xff`
image produces an all-zero mask.

The return is the original, pre-dilation valid fraction:

```text
floor(((pixel_count - invalid_ff_count) << 16) / pixel_count)
```

`FUN_180044300` does not consume that return. The later quality combiner counts
the propagated output mask independently.
