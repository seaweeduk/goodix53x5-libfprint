## Behavior

This post-classifier veto handles the `0x413000` type family when the first
dispatcher flag is still zero. It derives count and bitmap/detail combinations,
decodes the packed mode at `config[0x12]`, and clears both flags for multiple
mode- and count-dependent rejection families. Surviving type-12 candidates are
passed to `FUN_180057e60` for another veto.

### Raw packed-mode clear at `0x180053868..0x1800538ae`

After the preceding `metrics[14] == 1` family, this branch runs only while
`flag64` remains nonzero. It clears both flags when all of the following hold:

```text
config[18] != 0
metrics[9] > 200
combined = int32_wrap(
  metrics[8] + metrics[5] - config[0]
    - 4 * (metrics[12] + metrics[13] + metrics[14])
)
signed(combined) < 405
(
  (metrics[10] < 45 && metrics[11] < 15 && metrics[70] > 16)
  || metrics[4] == 128
)
```

The test at `0x180053872` is against the raw packed word. Unlike the earlier
family at `0x180053700..0x1800537ba`, it does not call `FUN_180070d90` and does
not require a particular decoded low or high class. The clear at
`0x1800538a4..0x1800538aa` also preserves mutable recognition mode
`config[19]`; only the two flags are written. The combined expression uses
32-bit dword arithmetic, so intermediate overflow wraps modulo `2^32` before
the final signed comparison.

### Mode-independent geometry clear

The gate immediately before the count-indexed switch clears both output flags
when any of the following signed comparisons holds:

```text
metrics[4] - config[0] - 2 * (metrics[12] + metrics[13] + metrics[14]) == 128
metrics[5] - config[0] - 2 * (metrics[12] + metrics[13] + metrics[14]) < 176
metrics[9] < 31
metrics[11] < 6
```

The arithmetic uses wrapping dwords. In particular, `0x180053a0b` compares
the unadjusted geometry word in `R15D` against five; the fallthrough stores at
`0x180053a11..0x180053a14` clear both flags. This gate does not test packed
mode or the combined detail sum and does not write `config[19]`. It therefore
also applies with raw `config[18] == 0`. The type-12 compact Boolean validator
`FUN_1800608b0` does not repeat this geometry-word predicate; its success alone
does not establish survival of this dispatcher gate. The geometry word remains
coupled to the record and affine producers described below.
