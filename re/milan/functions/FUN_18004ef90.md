## Exact Contract

The initial valid-mask minimum, maximum, and linearly interpolated 256-bin
histogram are built exactly as in `FUN_18004ce40`. Invalid arguments return
`0x80000002`; a nonpositive range writes the minimum threshold and returns
`0x80000003`.

For a positive range, `FUN_180050f70` clips/rebins the 0.5% tails and
`FUN_18004f990` emits secondary state 0 or 1. The wrapper separately finds the
35th and 50th percentile bins in the original histogram with cumulative targets
`floor(total * 35 / 100)` and `floor(total * 50 / 100)`, and maps each as:

```text
value = minimum + (range * bin + 128) / 255
```

The selected scalar starts as the mapped 35th percentile. If the mapped 50th
percentile exceeds it by more than 500, the selected scalar is replaced by the
50th percentile. It is finally capped to the caller's ceiling.

The caller writes the `FUN_18004f990` state to classifier context `+0x04`.
Both callers are entered only after retained reference count exceeds 20.
`FUN_18004e8c0` uses `profile9_history_reference`; a guarded
`FUN_18004dea0` fallback uses workspace `+0x04`, mapped to Linux
`state->calibration_map`. Both use the same mask:
outer three rows/columns clear, and each interior byte set only when eroded-valid
is nonzero and `reference_age * 100 >= history_count * 50`.

## Auxiliary Mapping

Context `+0x04` is not copied directly. `FUN_18006b290` first increments it once
when primary state `+0x00 == 2` or directional state `+0x0c == 2`, then copies
its low byte to auxiliary byte 2. Thus a fresh secondary state 0 generically
becomes auxiliary byte 2 value 1 when the primary state is 2.
