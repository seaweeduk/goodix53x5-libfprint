# FUN_180073540

## Identity

- Binary: `GoodixEngineAdapter.dll` 2.0.310.900.
- Entry/body: `0x180073540`, `0x180073540..0x18007381f`.
- Role: classify direct and warped binary matrices under two validity masks.

## Recovered Behavior

The effective signature is:

```c
void FUN_180073540(
  matrix_desc *direct,
  matrix_desc *warped,
  matrix_desc *direct_validity,
  matrix_desc *warped_validity,
  int32_t origin_y,
  int32_t origin_x,
  int32_t classes[4],
  int32_t *valid_count,
  int32_t *filtered_mismatch_count_or_null);
```

The iteration dimensions are:

```text
columns = min(direct.columns - origin_x, warped.columns)
rows = min(direct.rows - origin_y, warped.rows)
```

For crop-local `(x,y)`, the direct value and validity use global coordinate
`(x+origin_x,y+origin_y)`. The warped value and validity use local coordinate
`(x,y)`. A pixel is counted only when both validity bytes are nonzero and both
data bytes are below two.

The class index is:

```text
class_index = direct + warped * 2
```

Written as `(warped,direct)`, the array order is `[00,01,10,11]`. Written as
`(direct,warped)`, it is `[00,10,01,11]`. The function clears all four class
words and the valid count before iteration, so on normal input their sum equals
the valid count exactly.

When the final argument is nonnull, valid mismatches are first marked `0xff` in
an internal crop-sized byte matrix. `FUN_18006f840` and `FUN_180070820` apply
radius-two morphology in place; the function returns the final nonzero-pixel
count through that argument and releases the temporary matrix.
`FUN_180071d40 -> FUN_1800717e0` supplies a nonnull local count on both ordinary
bitmap passes, regardless of whether the outer caller requests argument-10
publication. `FUN_180072710` passes null.

## Ordinary Score Consumption

The optional morphology executes in ordinary profile-9/type-12 overlap, but
does not modify the four class counts, valid count, source images or validity
owners. `FUN_1800717e0` derives coverage, detail and initial confidence from
the class populations and full area. Mode selects the score path; nonzero-mode
scoring also consumes weights, count and carried confidence as specified in
`FUN_1800731d0.md` and `FUN_180071d40.md`. None of those calculations consumes
the morphology count. `FUN_180071d40` optionally publishes the maximum of the
two morphology counts; the count's value is not an operand of score replacement
or selected-detail relatching. Presence of the
outer count-output pointer selects a relatching rule independently of its value.
See `FUN_180071d40.md` for the two-pass publication and pointer-presence contract.
