The iteration dimensions are:

```text
columns = min(direct.columns - origin_x, warped.columns)
rows = min(direct.rows - origin_y, warped.rows)
```

For crop-local `(x,y)`, the direct value and validity use global coordinate
`(x+origin_x,y+origin_y)`. The warped value and validity use local coordinate
`(x,y)`. A pixel is counted only when both validity bytes are nonzero and both
data bytes are below two.

The class index is:

```text
class_index = direct + warped * 2
```

Written as `(warped,direct)`, the array order is `[00,01,10,11]`. Written as
`(direct,warped)`, it is `[00,10,01,11]`. The function clears all four class
words and the valid count before iteration, so on normal input their sum equals
the valid count exactly.

When the final argument is nonnull, valid mismatches are first marked `0xff` in
an internal crop-sized byte matrix. `FUN_18006f840` and `FUN_180070820` apply
radius-two morphology in place; the function returns the final nonzero-pixel
count through that argument and releases the temporary matrix.
`FUN_180071d40 -> FUN_1800717e0` supplies a nonnull local count on both ordinary
bitmap passes, regardless of whether the outer caller requests argument-10
publication. `FUN_180072710` passes null.
