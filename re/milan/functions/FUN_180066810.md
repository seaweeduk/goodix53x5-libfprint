## Behavior

- Counts qualifying samples over `rows * columns` and returns true only when
  the count is strictly greater than `pixel_count * 205 / 256`.
- In signed mode it counts samples whose absolute signed value exceeds `100`,
  except a 60-column input uses threshold `0x1068`.
- In unsigned mode it counts samples greater than `10` when the polarity flag
  is zero, or samples below `0xff5` when the flag is nonzero.
- Production profile 9 / packed subtype 12 does not call this generic helper.
  `FUN_180067500` instead sets admission from its mask structure count using
  an initial 80% test, then the subtype-12 override
  `pixel_count * 9 < admitted_count * 10`. Native subtype-12
  preprocessing must therefore use the `FUN_18006a4c0` mask count captured
  before later rendering-mask hole fill, not apply this helper's generic
  `>100` rule to the setup-offset working source.
