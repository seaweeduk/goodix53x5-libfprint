## Behavior

Null input returns `0x80000002`. Types `9`, `10`, `17`, and `18` skip the
normalization call; other types, including production type `12`, invoke
`FUN_180047120` and return success.

For type 12 this means parsed tag `bb` is only an input-format field: complete
unpack recomputes live `+0x128` from masks and relation state before the object is
repacked or used. Direct control changes a native sequence-35 object from
feature values `88/320` to official `67/252` and produces the exact official
469,148-byte object.

At the enrollment caller `FUN_180042c30`, this wrapper runs only when live
feature count equals physical maximum `+0x20` (40 for type 12), after
`FUN_18007a040`. It does not run merely because the session reaches its requested
sample count.

## Type-12 Mutation Contract

`FUN_180047120` first materializes a feature's internal packed mask at `+0x140`
from its inline mask when that cache is absent. For type 12, context `+0x0c` is
one, so the normalization domain is half-resolution `52 * 44 == 2288`.

For every live feature, in physical order, it unconditionally writes zero to the
internal overlap count at `+0x148` and 2288 to `bb/+0x128`. If `b5/+0x110` is
zero, those are the final values. If `b5` is nonzero, it obtains the feature's
transform to `f2`, removes every other nonzero-active feature footprint in the
same reference frame, and counts the residual mask through the native lookup
table. Residuals below 20 become zero; all other residual counts become `bb`.
For each other active footprint whose returned area is strictly greater than 40
percent of the full `104 * 88` domain, it increments `+0x148`.

The function does not write `b5`, any other packed feature scalar, relations,
feature/relation counts, `f2/f3/f4/f5`, order, queue, or tail state. The `+0x140`
cache and `+0x148` overlap count are not serialized by `FUN_180040a70`; only the
mandatory packed tag `bb` exposes normalization. A fully connected 40-feature
state can therefore remain packed-byte identical when every active `bb` remains
zero even though all internal overlap counts are recomputed.

For a graphless 40-feature state, every feature remains inactive and every
packed `bb` changes from 0 to 2288. For an established partial state with only
features 0 and 1 active, their `bb` remains zero and internal overlap counts
become one, while inactive features 2 through 39 change `bb` from 0 to 2288.
Relations, active flags, metadata, order, and tail remain exact. In a sparse
post-closure control, active features 0 and 2 become `bb=95`, inactive feature 1
and all other inactive features become 2288, and the two active overlap counts
become one.

Production `c182b140` invokes the native normalizer for every exact-40
`goodix_match_combine_templates()` result after closure and reference-star
projection. Graphless, established-partial, and fully connected capacity
controls therefore cross this boundary; below-capacity output, including the
default DLL adapter and libfprint 12-stage paths, does not. Requested-8 oracle
evidence exercises the same below-capacity behavior but is nondefault.

## Malformed Reference Boundary

A CRC-valid one-feature packed object with `f2=1`, `f5=1`, and inactive `b5=0`
is malformed but can return from DLL unpack because this normalizer does not
dereference the reference for an inactive feature. Changing only `b5` to 1
causes the approved DLL to fault at `FUN_180047120:0x1800472bd`, reading
`feature[reference]+0x114` through the null out-of-range slot. Current unpack and
`goodix_match_combine_templates()` reject both forms before graph consumers; the
active form returned `NULL` rather than entering native normalization. This is
malformed-input hardening, not a production enrollment difference: constructor
and enrollment graph publication keep `f2` in range whenever `f5=1`.

Evidence is the wrapper mask test at `0x180047563..0x180047574`; domain setup is
at `0x1800471a7..0x1800471bc`, unconditional `+0x148/+0x128` initialization at
`0x180047260..0x180047278`, active-footprint processing at
`0x18004727e..0x180047478`, residual threshold/write at
`0x180047489..0x1800474f1`, and inactive completion at `0x1800474f7`.
