## Profile-9/Type-12 Contract

The two calls operate on the caller-selected ranges `[0,boundary)` and
`[boundary,count)`; this helper does not derive boundaries from record flags.
For each enrolled source it applies the following contract:


an equal best preserves the earlier best but may lower second, while an equal
second preserves the earlier second. This helper receives neither `180x180`
matrix used by `FUN_180075220`; it computes both tail orientations directly.

## Fixed-Width Affine Arithmetic

`FUN_180075dc0` calls `FUN_1800689a0` before scanning. The inverse determinant
uses wrapped dword semantics; a wrapped-zero determinant copies all six input
words. Nonzero inversion uses signed division toward zero. The scan then uses
wrapped dword products and additions in both transform directions. Pixel
coordinates use the ordered `+0x80; SAR 8` rounds, while residual magnitude uses
wrapped subtract/reverse-subtract. The relevant scan is
`0x180075ea0..0x180076052`.

Current `goodix_milan_match_cross_class_alternate_correspondences()` uses widened
`int64_t` products for the forward transform instead of this dword wrap. An
extreme but accepted synthetic-valid affine and 16-bit coordinate can therefore
be admitted by the DLL after forward wrap and rejected by current source.
Retained natural profile-9 rows did not approach this overflow boundary; that is
negative corpus evidence, not a general unreachability proof.

This guided cross-class affine-width difference is deferred. It remains in
`origin/milan-dev`, this documentation worktree, and the separate pending
collision patch. It is not part of the signed-dword spatial-collision or
post-replacement correction described in `FUN_180075a60.md`.

## Failure Ownership

`FUN_1800689a0` has no error return. Null input or output is a no-op. Its six
nonzero-determinant divisions occur at `0x180068a07`, `0x180068a19`,
`0x180068a34`, `0x180068a52`, `0x180068a62`, and `0x180068a6e`. A malformed
extreme transform that presents `INT64_MIN / -1` raises the native integer
division exception. Current source checks and rejects that state before pair
publication. This fail-closed result deliberately differs from a native crash;
it must not be described as parity for accepted synthetic-valid input.
