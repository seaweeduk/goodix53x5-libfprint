# FUN_1800039b0

## Audit Scope

Dynamic-configuration loader that references the literal key
`IsOpenAntiFake`. This note was created before first Ghidra decompilation during
the scoped production argument provenance audit.

## Questions

- What default and parsed values are assigned to `IsOpenAntiFake`?
- Where is the value stored before it reaches engine-context offset `+0x1c4`?

## Audit Findings

- Reads optional `HKLM\\Software\\Goodix\\FP\\IsOpenAntiFake` data and stores
  its low byte at global `0x1800f1423`.
- The compiled byte at `0x1800f1423` is `1`; a missing registry value preserves
  that default.
- The installed `usbinterface.inf` has no `IsOpenAntiFake` override.
