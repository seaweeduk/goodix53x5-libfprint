## Output Invariants

For ordinary raw quality `0..100`, band tests `band <= k` in these rows
are exactly `quality <= 10*(k+1)`. The strict phase therefore has no hit above
quality 70, and the broad phase has no hit above quality 50. Coverage below
35 permits no write. Coverage `35..64` permits candidate writes but never a
match write, including on a strict-row hit. A caller using zeroed temporary
outputs thus receives only `(0,0)` or `(0,1)` in that coverage interval.

For primary 11, the terminal broad term (`band <= 2`, `m10 >= 47`,
`m5 > 191`) implies the first term (`band <= 4`, `m10 >= 47`,
`m5 >= 187`). Equality `m5 == 191` also satisfies that first term whenever
the terminal term's other predicates hold. The terminal comparison therefore
cannot determine this row's output independently of the first term.
