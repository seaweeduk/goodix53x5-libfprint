## Behavior

Type 12 passes the initial legacy-type rejection and receives a fixed stack
configuration with initialization through `FUN_180046ec0`. It calls
`FUN_180055a40`, the same matcher body selected by ordinary dispatcher
`FUN_18005edb0` for profile 9/type 12.

The type-12 configuration includes fixed words `5`, `218`, `23`, `47`, `40`,
`38`, and `-1`.

After the matcher returns, the wrapper marks its local evidence object live,
calls `FUN_180044fc0(template, probe, evidence, result)`, copies the returned
study action to the caller, and returns zero. Thus the type-12 path is match
followed by study against the same live template/probe/evidence transaction; it
does not bypass the lifecycle or queue dispatchers.
