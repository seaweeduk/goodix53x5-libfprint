## Contract

The five-argument Windows x64 ABI is:

```c
void propagate_higher(context, pivot_to_reference, int32_t pivot,
                      overlap_context, int32_t threshold);
```

Native reads signed live feature count from context `+0x1c`. It scans ascending
from `pivot+1` through `feature_count-2`, inclusive. The last live feature,
`feature_count-1`, is the caller's current enrollment feature and is excluded.
This is equivalent to current source's explicit `candidate < current` range
when `current == feature_count-1`. There is no independent capacity or pointer
validation.

For each candidate, an exact active word of `1` is skipped. Any other value is
eligible. The direct candidate/pivot slot must have a nonnegative leading signed
dword; negative undefined slots are skipped without overlap. `FUN_180071d40`
receives candidate first, pivot second, the direct canonical slot transform, and
the supplied overlap context. Admission is the strict signed predicate
`overlap_return > threshold`; profile 9 supplies 205, equality is rejected, and
206 is admitted.

Every admitted candidate is independent. Native computes exactly:

```text
candidate_to_reference = compose(pivot_to_reference, E(candidate, pivot))
```

`FUN_180068860` normalizes that result immediately. Higher candidates are not
placed on a worklist and never become parents for later higher candidates. Thus
multi-hop expansion belongs to the lower helper; this helper is a direct star
from the pivot even when several higher candidates pass.

The first operand is the same caller stack-local `pivot_to_reference` supplied
to the lower helper. Native does not reload the pivot/reference canonical slot.
It sets the admitted feature active before canonical storage. If candidate is
below the live reference, it inverts the composed result for higher-to-lower
triangular orientation; otherwise it copies the composed result. Transform words
are written before the leading dword is set to zero. Inversion is non-failing
and copies singular input; no status is returned by compose, invert, or this
helper.

Candidates are scanned once in ascending order, so cycles and duplicate
opportunities cannot cause reprocessing. A failed or at-threshold overlap skips
only that candidate and leaves earlier accepted writes intact.
