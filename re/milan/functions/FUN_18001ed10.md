# FUN_18001ed10

## Identity

- DLL: `GoodixEngineAdapter.dll`
- Address: `0x18001ed10`
- Logged name: `EngineAdapterDetach`
- Role: engine/preprocessor lifetime teardown callback.

## Findings

- The callback is stored in the adapter callback table at `0x1800f22b8`, after
  `EngineAdapterAttach` at `0x1800f22b0`, and has no direct in-DLL code caller.
- Frees the engine-owned `0x1c` object at context `+0x190` and the `0x4c98`
  auxiliary object at `+0x198`.
- Calls `_Detach_Unify` (`FUN_180030f40`) at `0x18001ee7d`.
- `_Detach_Unify` calls `FUN_18002b7e0`, whose `0x18002b84a` call reaches the
  preprocessing exit routine and releases retained preprocessing globals.
- On successful detach it releases cached templates, frees the complete engine
  context, clears adapter field `+0x38`, and restores adapter state `+0x08` to
  `-1`.

## Lifetime Consequence

Preprocessor calibration survives multiple probes and biometric operations only
while this engine attachment remains alive. It does not survive adapter detach,
even if the lower usbinterface hardware context remains attached.

## Unresolved

- Which WBF/Biometric Service idle and power events invoke this externally
  registered callback. The adapter DLL contains no scheduler for its own attach
  or detach callback.
