## Independent Affine Ranking

For type12 alternate bitmap overlap and affine diagnostics precede the
alternate-versus-primary count comparison (`0x18005a6f3..0x18005a806`).
The alternate replaces the ranked affine only when its signed score is above128
and its penalized detail is strictly greater:

```text
rank = detail - 4 * (scale_penalty + orthogonality_penalty)
```

Additions, shifts and subtraction are wrapping dword operations. A score of128
or equal rank retains every incumbent field. The count may be greater, equal,
or lower: count does not participate in this ranking. A win copies the affine,
score/detail, scaled coverage and all three penalties together. It does not
promote word1. Each overlap result belongs to the count supplied to that call;
there is no recomputation with a later retained count inside this function.

`FUN_180070e90` supplies average column length and absolute normalized Q16 dot.
Scale penalty is unsigned `average_scale-234 > 47`, hence outside inclusive
234..281. The two dot penalties are respectively `>=0x147b` and `>=0x28f6`.
Folded rotation is a separate diagnostic, not the scale-penalty operand.

## Count Promotion And Record Repair

Only a strictly larger alternate count enters `0x18005a80e..0x18005a8a2`:

1. `FUN_1800723b0` uses the **currently ranked affine**. It forward-maps every
   active expanded probe-mask pixel and counts active destination-mask hits,
   using nearest-neighbor coordinates and the full source expanded-mask area as
   denominator. Nonzero resolution mode halves translations and multiplies the
   raw hit count by4 without changing the percentage.
2. Its percentage is multiplied by246 in a dword and arithmetically shifted
   right8 before promotion.
3. `FUN_180074e80` uses the **local alternate affine and alternate count**,
   independently of the rank winner. The complete11-word result is written to
   words66..76; topology and geometry are copied to words10 and11.
4. Word1 becomes the alternate count if any following term is true:

```text
mask >= 145 && topology >= 40
mask < 105 && topology > 65 && geometry > 50
mask >= 105 && topology >= 45 && geometry > 25
geometry > 80
alternate_count > 18
```

Finally, original primary count `>4` and current topology `<30` cause one repair
call at `0x18005a93b`. It uses the **ranked affine and original primary count**
and overwrites only words10/11 and66..76. It does not undo count promotion or
rank selection and is not retested. Equality at primary4 or topology30 does not
repair. Thus final record ownership is:

| State | Record owner |
| --- | --- |
| No larger alternate, primary at most4 | Caller-zeroed fields |
| No larger alternate, primary above4 | Ranked affine / primary count |
| Larger alternate, no repair | Local alternate affine / alternate count |
| Larger alternate, repair | Ranked affine / primary count |

For valid transformed recordsV, matched recordsM and supplied countN,
`FUN_180074e80` returns `[V,M,trunc(100*M/V),trunc(100*N/V),mean_tail_distance]`.
Both percentages are zero forV=0. Geometry is not clamped to100 or36 and does
not use image coverage as denominator. See `FUN_180074e80.md` for the spatial
and descriptor contract.

## Failure And Defined-State Boundaries

The primary affine starts as caller identity. Fewer than3 selected pairs make
`FUN_18005b900` return zero without writing it. Attempted fitting with no model
writes affine zero and returns zero; valid fitting followed by orientation
rejection can also return0,1 or2 while retaining a defined model. All three
zero-count families skip alternate construction and still reach sibling.
Identity/zero words alone do not encode model validity. See `FUN_18005b900.md`
and `FUN_180077e20.md` for mask, residual, budgets and refinement ownership.

The alternate local `[RBP-0x50..RBP-0x3b]` is not initialized before filtering.
Below3 selected pairs leave it indeterminate, yet the DLL passes it to overlap
and diagnostics at `0x18005a746/0x18005a756`. A rank win copies it to the ranked
output at `0x18005a7af..0x18005a7fb`. Alternate count0 cannot enter promotion
because primary is positive, but primary>4 can subsequently repair records from
the tainted ranked affine; lower primaries carry it directly to sibling.
Attempted alternate fitting with no model instead supplies defined affine zero
to the same overlap/rank path. The DLL has no candidate-validity bit.

The established deterministic implementation policy ignores either invalid
alternate family, retains the independently valid primary state, and performs
only ordinary primary-only repair. It does not assign a parity value to
indeterminate stack bytes or admit a failed model by its zero value. An invalid
primary can recover through an independently fitted class sibling; that path
does not need the invalid incoming affine.

## Arithmetic Boundaries

Affines are signed Q8 dwords; record coordinates are unsigned16-bit Q8.
Alternate/guided inversion uses a wrapped-dword determinant, signed64-bit
numerators and truncating division, then narrows outputs to dwords. A wrapped
zero determinant copies input unchanged. Scan multiply/add/round/shift and
residual tests use dword wrapping; they are distinct from the record-metric
helper's signed64-bit coordinate products. See `FUN_1800689a0.md` and
`FUN_180074ba0.md`. The signed-division overflow case has no successful native
result. Caller validation of malformed partition metadata is separate from
these valid-boundary arithmetic contracts.
