## Ranking And Selection

The alternate affine wins the metric/transform ranking only when its overlap
score is strictly above `128` and its penalized detail is strictly greater:

```text
primary_rank = primary_detail - 4 * (primary_angle_flag + primary_ortho_flag)
alternate_rank = alternate_detail - 4 *
                 (alternate_angle_flag + alternate_ortho_flag)
```

Count promotion is separate from transform ranking. It first requires
`alternate_count > primary_count`, then promotes for template types `11` and
`21`, or when any recovered generic condition succeeds:

```text
mask_overlap >= 145 && topology_percent >= 40
mask_overlap < 105 && topology_percent > 65 && geometric_percent > 50
mask_overlap >= 105 && topology_percent >= 45 && geometric_percent > 25
geometric_percent > 80
alternate_count > 18
```
