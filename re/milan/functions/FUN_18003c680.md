## Behavior

This is the watershed propagation stage for the anti-fake class map. It forces
the outer border to `0xfe`, discovers unassigned interior pixels adjacent to an
assigned four-neighbor class, and queues them by the minimum absolute source-
image difference. The queue is processed in ascending difference order.

An unassigned pixel inherits a common nonzero four-neighbor class. Conflicting
neighbor classes become `0xff`; queued-but-unresolved pixels use `0xfd` while
pending. Newly exposed four-neighbors are enqueued with their absolute image
difference, preserving the 0..255 bucket order.

Border exclusion overwrites labels, not image bytes. Initial discovery includes
every nonzero neighbor label, including the excluded border, when computing the
minimum full-byte intensity difference. First-row image metadata can therefore
change queue priorities for the next row even though the first row's own labels
are all `0xfe`.

Within each difference bucket, insertion prepends to the head and removal takes
that head, giving LIFO tie order. Neighbor inheritance also includes queued
`0xfd`, excluded `0xfe`, and conflict `0xff` labels. A popped pixel assigned
`0xff` does not enqueue any neighbors. The class map, not queue priorities or
pop order, is passed back to `FUN_18003ad10`.
There is no distinct resolved-label conversion after a pop: a common neighboring
`0xfd` label can remain `0xfd` in the returned map.
