## Behavior

The function copies the transform and reads both mode words. When `mode[0]` is
nonzero, each copied translation is halved by `INC; CDQ; SUB; SAR`, equivalent
on production values to signed `(value + 1) / 2` with truncation toward zero.
It expands descriptor views from `first+0x28` and `second+0x28` through
`FUN_1800721a0`, supplies their `+0x18` low bitmaps, expanded inline masks,
`mode[1]`, and the caller workspace to `FUN_18006fc80`, then releases both
temporary views. The return value is the core helper's return value.

At `FUN_180055a40:0x18005624a..0x180056267`, `first` is the live probe
and `second` is the selected enrolled feature. The transform maps probe/source into
enrolled/target coordinates. Thus the enrolled low bitmap and expanded enrolled
inline mask remain direct target-owned matrices; only the probe low bitmap and
expanded probe inline mask are warped and cropped. This direct call is
conditional: `FUN_180055a40:0x180056236..0x180056244` skips it, together with
the following `FUN_180053220` call, when `flag60 == 2` and signed accumulated
high class is at most one. Candidate words 6..8 then retain their caller-owned
zero initialization for the later `FUN_180058700` policy.

At the `FUN_18005d5f0` fallback boundary, the retained winner's transform and
feature are passed here only after the candidate loop has finished. The compact
workspace is subsequently completed with affine diagnostics and passed to
`FUN_1800608b0`. This recomputation does not select the fallback winner and does
not update the rejection `count_sum`, seen latch, maximum adjusted metric, or
winner-carried coverage.

The core distinguishes unavailable cropped images from zero classified support.
`FUN_18006f390` leaves its output owners null when the clipped rectangle has
nonpositive width or height. With both cropped owners present,
`FUN_18006fc80` calls `FUN_180073540` and returns one even if every class count
is zero; its three guarded denominator calculations then write zero to words
6..8. Zero shared mask support is therefore not the untouched-output failure
case. This wrapper does not mutate either input feature, bitmap, inline mask,
or the supplied affine.

Positional ownership is explicit below the wrapper: `FUN_18006fc80` expands
input block `+0` and passes that expanded matrix with block `+0x10` to
`FUN_18006f390` at `0x18006fd38`. Block `+8` and `+0x18` are the direct bitmap
and mask supplied to `FUN_180073540` at `0x18006fd83`. The current public
low-metric helper takes enrolled operands before probe operands, reversing the
native wrapper's first/second descriptor order without reversing the affine.
