## Consequence For Oracle Replay

Post-`identifyImage` template bytes are a useful diagnostic snapshot, but they
are not independently persisted by the production adapter. The next operation's
persistent input changes only when `templateStudy` produces a positive update
and `_CheckUpdateTemplate_E` packs that updated object. A zero-update replay must
retain the previously loaded persistent template, not the after-match or
after-study in-memory snapshot.
