## Input And Direction

The input block has probe/source low bitmap at `+0`, enrolled/target low bitmap
at `+8`, expanded probe mask at `+0x10`, expanded enrolled mask at `+0x18`,
an unused owner slot at `+0x20`, transform pointer at `+0x28`, and warp option
at `+0x38`. `FUN_180073a90` expands both packed low bitmaps as contiguous
LSB-first `52x44` matrices. `FUN_18006f390` warps only the first bitmap and mask
into the destination-clamped second frame. The second bitmap and mask remain
full-size direct target matrices.

`FUN_180073540` computes `c00,c01,c10,c11` with class index
`direct_target + warped_source*2`. Crop origin is added only to direct target
reads. The cropped bitmap and mask use crop-local coordinates.

### Image-Owner Preconditions

For the type-12 wrapper, each full image descriptor is `104x88`, each packed
low bitmap is `52x44` (286 bytes, contiguous LSB-first), and each inline mask is
`26x22` (72 bytes including padding). Mode `[1,0]` expands each inline bit to
a `2x2` validity tile. The descriptors and storage remain alive through cleanup,
and the caller supplies writable metric words 6..8 and a six-word Q8 affine.
This boundary consumes no feature records, correspondence counts, admission
flags, or image-quality metadata.

Positive classified support is not an input precondition. `FUN_18006f390`
computes the clamped rectangle from dimensions and transformed corners before
sampling validity. Thus a nonempty geometric crop can contain no jointly valid
pixels, including when each input mask is individually nonempty. Successful
allocation of both cropped owners reaches `FUN_180073540` at `0x18006fd83`,
which initializes all class counts and valid total to zero. Its mask checks may
leave every count zero. The guarded stores at `0x18006fde4`, `0x18006fe02`, and
`0x18006fe1e` still execute, followed by success at `0x18006fe22`. This is a
defined empty comparison, distinct from the null-owner failure branch.

## Metric Publication

After releasing temporary owners, the helper writes three rounded Q8 ratios at
candidate byte offsets `0x18`, `0x1c`, and `0x20`:

```text
word 6 = round_Q8((c00 + c11) / (c00 + c01 + c10 + c11))
word 7 = round_Q8(c00 / (c00 + c01 + c10))
word 8 = round_Q8(c11 / (c01 + c10 + c11))
```

Each class sum, numerator shift, rounding addition, and result uses signed
dword arithmetic. For a positive denominator, `round_Q8(n/d)` is
`((n << 8) + (d >> 1)) / d`, truncating toward zero. Production class counts
are nonnegative and bounded by 2,288, so this is ordinary half-up rounding
without wrap. Zero denominators produce zero.

If either required warped owner is null, cleanup returns zero without writing
any of the three metrics. With both owners present, all three metrics are written
and the return is one, including when every class count is zero. All other
candidate words are untouched. Input bitmaps, masks, descriptors, and transform
are read-only. The ordinary direct caller ignores the return before its next
stage, so failure preserves its caller-initialized words 6..8.
