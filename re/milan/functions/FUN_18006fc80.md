## Recovered Behavior

The input block contains, in order, the enrolled low bitmap, probe low bitmap,
expanded enrolled inline mask, expanded probe inline mask, transform, and warp
option. `FUN_180073a90` expands both packed low bitmaps as contiguous LSB-first
`52x44` matrices. `FUN_18006f390` warps only the probe bitmap and probe mask into
a destination-clamped enrolled frame. The full enrolled bitmap and enrolled
mask remain direct target-owned matrices.

`FUN_180073540` then computes `c00,c01,c10,c11` with class index
`target + warped_probe*2`. The helper releases all temporary objects before
writing three rounded Q8 ratios to candidate byte offsets `0x18`, `0x1c`, and
`0x20`, which are words 6, 7, and 8:

```text
word 6 = round_Q8((c00 + c11) / (c00 + c01 + c10 + c11))
word 7 = round_Q8(c00 / (c00 + c01 + c10))
word 8 = round_Q8(c11 / (c01 + c10 + c11))
```

Each class sum, numerator shift, rounding addition, and result uses signed
dword arithmetic. For a positive denominator, `round_Q8(n/d)` is
`((n << 8) + (d >> 1)) / d` with signed division truncating toward zero.
Production class counts are nonnegative and bounded by 2,288, so all reached
ratios are ordinary half-up rounding without wrap.

If either required temporary result is null, it performs cleanup and returns
zero without any of the three candidate stores. On success it writes all three
metrics and returns one. Zero denominators produce metric zero; positive
denominators use half-up integer rounding.
