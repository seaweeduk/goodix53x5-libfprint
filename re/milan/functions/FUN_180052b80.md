## Exact Contract

For each masked pixel whose source is strictly greater than `start_threshold`,
follow up to four entries in the direction plane from `FUN_180051bd0`. Stop
before adding when direction is negative, current source is below
`current_floor`, or the selected neighbor is below `next_floor`. Otherwise add
the current gradient as uint16 and move to that neighbor.

`next_floor` is zero normally and `current_floor - 50` only when the final mode
argument is one. Profile-9 `FUN_18004e8c0` passes the histogram threshold as
both `start_threshold` and `current_floor`, and mode zero. That threshold comes
from `FUN_18004ef90`; its percentile selection and 9000 cap are described in
[`FUN_18004e8c0.md`](FUN_18004e8c0.md).

Source comparisons are signed-word values promoted to signed dwords. Equality
with the start threshold suppresses a score; equality with either floor permits
the step (`0x180052c93..0x180052cd4`). Each addition and index advance is a word
operation. A four-step path need not stop at a local minimum. The output is
written at every pixel, including zero for unmasked or start-ineligible pixels
(`0x180052ced..0x180052cfc`). The source, gradient, direction, and qualification
planes are unchanged. The consumer `FUN_180051160` interprets the resulting
score words as signed values.

For a nonnegative signed-word source, selected edges from `FUN_180051bd0` are
strictly descending, so the accumulated score telescopes to the start value
minus the final value. It remains in 0..32767 without word wrap. No spatial
sorting is performed: direction tie order belongs to `FUN_180051bd0`, and
subsequent region growth belongs to `FUN_180051f50`. The current counterpart is
the four-step loop in `milan_profile9_temporal_class3()`.
