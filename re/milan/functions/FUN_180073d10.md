## Recovered Behavior

The helper clears a two-byte-per-pixel matrix to `-1`, rounds every record's Q8 coordinates to a pixel, clamps a square search radius to the matrix, and writes the record index to every pixel in that square. Later records overwrite earlier records. `FUN_180072860` builds one map per foreground partition with radius two and reuses the maps across enrolled features.

## Matrix And Index Contract

`+0x18`. The helper reads unsigned 16-bit Q8 coordinates at record offsets 2/4,
rounds each as `(coordinate+128)>>8`, and visits both endpoints of each clipped
square. An empty clipped range writes nothing. Index values begin at zero for
the supplied record pointer, including when that pointer is the second stored
partition. `FUN_180073ba0` owns the eventual physical-index rebasing.
