## Recovered Behavior

For affine linear part `[a,b;c,d]`, each scalar product is a wrapping signed
dword multiplication which is then sign-extended. It forms
`first=a*a+b*b`, `cross=a*c+b*d`, `second=c*c+d*d`, all as signed 64-bit sums,
then computes wrapping signed-64 `trace=first+second` and
`disc=trace*trace+4*(cross*cross-first*second)`. Both `disc` and `trace` must be
nonnegative.

The two integer arguments are shifted left nine as dwords before signed
extension. With the profile-9/type-12 call `(upper,lower)=(401,163)`, define
`lo=(lower<<9)-trace` and `hi=(upper<<9)-trace`. Acceptance is exactly
`lo <= 0`, `hi >= 0`, `disc < lo*lo`, and `disc < hi*hi`; both squared-bound
equalities reject. The products in those final comparisons are wrapping signed
64-bit. This is equivalent to strict lower/upper characteristic limits, not
inclusive limits. The upper equality is reachable by ordinary integer linear
parts and rejects. The nominal lower equality is not realizable by an ordinary
integer 2x2 linear part, but its strict branch remains part of the malformed
wrapped-input contract.
