# FUN_180072710

## Identity

- DLL: `GoodixEngineAdapter.dll`
- Address: `0x180072710`
- Body: `0x180072710..0x180072857`
- Role: warp a temporary binary mask into a second mask's frame, classify it
  under two validity masks, and fold four classes into three outputs.

## Recovered Signature

Ghidra and the x64 calling convention recover the effective signature as:

```c
bool FUN_180072710(
  masked_context *context,
  int32_t outputs[3]);
```

`outputs` receives `[class0, class1 + class2, class3]`. The return value is
false when `context->warped_validity` at offset `+0x20` is null. With a
nonnull warped-validity owner it unconditionally proceeds from `FUN_18006f390`
to `FUN_180073540`, then returns one. There is no empty-crop/null-result
check after the warp call. The classifier dereferences its warped descriptor
at entry, so a valid nonempty crop is a caller precondition, not a recoverable
false return from this helper.

### Matrix descriptor

The fields consumed by this helper and its direct callees are:

```text
+0x00 int32_t columns
+0x04 int32_t rows
+0x08 int32_t byte row stride
+0x0c int32_t data allocation size in bytes
+0x10 int32_t element size/type selector
+0x18 uint8_t *data
```

For these one-byte temporary matrices the first five fields are
`[columns, rows, columns, columns*rows, 1]`. `FUN_180068700` allocates the
descriptor and data together and sets `data = descriptor + 0x20`; the parent
instead uses stack descriptors pointing at its separately allocated byte planes.

`FUN_18006f390` writes crop origin to context words `[6]` and `[7]`, which
become `origin_x` and `origin_y` arguments to `FUN_180073540`.

### Parent temporary masks

this helper:

```text

other -> clear original expanded probe validity; temporary byte remains unwritten
```

## High-Level Pseudocode

```c
if (!context->warped_validity)
  return false;

copy first-mask dimensions and crop configuration;
FUN_18006f390(context->first_mask, NULL, context->transform,
              &warped_first_mask, NULL, &crop_context);

classes = {0, 0, 0, 0};
valid_count = 0;
FUN_180073540(context->second_mask, warped_first_mask,
              context->direct_validity, context->warped_validity,
              origin_y, origin_x, classes, &valid_count, NULL);
release(warped_first_mask);

outputs[0] = classes[0];
outputs[1] = classes[1] + classes[2];
outputs[2] = classes[3];
return true;
```

## Constants And Branches

- The parent enters this path when its mode descriptor selects masked
  reclassification.
- Parent-side mask remapping constants are `1 -> 0` and `2 -> 1`.
- The parent allocates both temporary masks with `FUN_180003800` (plain
  `malloc`) and copies the first mask to the second with `FUN_18008a9c0`.
  There is no zero initialization. See `FUN_180071d40.md` for the two validity
  owners and the lifetime of unwritten temporary pixels.
- Warped output bytes are initialized to `0xff`; `FUN_180073540` only accepts
  direct and warped values below `2`.
- `FUN_180073540` uses `class_index = direct + warped * 2`.
- Output folding is exactly `[class0, class1 + class2, class3]`.
- The optional morphology/mismatch output of `FUN_180073540` is null here, so
  its `FUN_18006f840` and `FUN_180070820` path is not entered by this helper.
