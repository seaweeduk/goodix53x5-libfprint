## Complete Type-12 Queue Contract

Ranks encode insertion age as a contiguous permutation `0..occupied-1`; `-1`
means empty. The helper finds the maximum rank (newest) and minimum rank/empty
slot. While queue state is 0 and an entry exists, it compares the incoming live
probe only with the newest entry through `FUN_180071d40`; result `>190` suppresses
the enqueue as an adjacent duplicate. Otherwise `FUN_180045a50` deep-copies the
probe into the selected slot.

Both rank scans update their selected slot only on a strict comparison. For a
valid queue this makes the newest owner unique; among multiple rank-`-1` slots,
the first physical slot wins. Duplicate score exactly 190 is not suppressed and
is enqueued. The helper changes only the selected body and rank array: it does
not increment or otherwise consult queue transaction counter `+0x8e04`.

Assembly `0x18004631f..0x1800463ca` fixes the comparison operand order as
incoming probe first and newest queued owner second, with an identity transform.
The descriptor is `{gallery[+0x0c],0,0}`, argument 9 is 10, argument 10 is
a local output, and argument 11 is null. In particular, descriptor word 2 is
zero, selecting `FUN_1800740f0` through `FUN_1800717e0`, not the ordinary
nonzero scoring mode. `FUN_180071d40` evaluates live matrix `+8`, then matrix
`+0x10` when both secondary owners exist; it may return the secondary score
when that score strictly exceeds primary and secondary detail is greater than
195. The returned value, not an individual low-bitmap equality output, is
compared with 190. See `FUN_180071d40.md` for the two-pass selection contract.

If full with ranks `0..19`, the minimum-rank slot is overwritten, every occupied
rank is decremented, and the new entry receives rank 19. A controlled full queue
therefore transitions physical ranks `[0,1,...,19]` to
`[19,0,1,...,18]`. Before capacity, an empty slot receives `max+1`.

The helper does not validate its input state or ranks. State 1 skips only
duplicate comparison; an unguarded direct call can still copy. The maximum scan
starts at `-100`, the minimum scan at `slot_count+1`, and both selected indices
start at `-1`. Canonical allocated storage and contiguous ranks are caller
invariants, not checks performed here.
