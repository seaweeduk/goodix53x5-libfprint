# FUN_180072600

## Identity

- Binary: `GoodixEngineAdapter.dll`.
- Binary SHA-256:
  `6673db3874fea66a58e2da29e371d797b890c767ba0491134d4a372c5b27e3b4`.
- Entry/body: `0x180072600..0x18007270d`.
- Role: clear row intervals from an LSB-first packed-bit matrix.

## Behavior

The helper consumes the first/last active row and one inclusive start/end column
pair per row produced by `FUN_180071370`. It clears each interval in place,
using boundary-byte masks and zeroing complete interior bytes. Matrix row stride
comes from header offset zero and payload storage from `+0x18`.

`FUN_180047120` uses the same destructive operation on a fresh clone of each
active feature mask. It visits every other active feature in ascending index
order and then popcounts the remaining bytes to produce tag `bb`.

For the aggregate rescue, each eligible transform is converted to intervals and
removed from the same cloned working matrix. Later area increments therefore
measure only cells not removed by earlier candidates.

## Interval Layout And Ownership

The interval owner contains signed first/last row at dwords 0/1, inclusive start
columns at dword `2+y`, and inclusive end columns at dword `0x102+y`.
`first_row > last_row` performs no writes. For each visited row, the helper
converts `start` and `end+1` to byte indices and bit offsets. It preserves bits
below `start`, bits at and above `end+1`, and all bytes outside the interval.
An `end+1` aligned to eight does not touch the following byte.

Only matrix payload is mutated; the matrix header and intervals are read-only.
There is no area return or mask-dependent count. Normalization's neighbor count
uses the geometric area already returned by `FUN_180071370`, whereas rescue
separately measures the changing residual. The direct rescue call is
`FUN_18005d9e0:0x18005dbea..0x18005dbf2`.
