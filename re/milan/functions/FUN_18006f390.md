## Crop Geometry

`FUN_1800800e0` transforms the four corners in top-left, top-right,
bottom-right, top-left-column/bottom-row order. Each product and addition,
including the `0x80` rounding bias, wraps to dword before the arithmetic `>>8`.
It does not use a widened geometric bounding box. The helper takes signed minima
and maxima and clamps them to the inclusive destination rectangle:

```text
minimum_x = max(min(corner_x), 0)
minimum_y = max(min(corner_y), 0)
maximum_x = min(max(corner_x), destination_columns - 1)
maximum_y = min(max(corner_y), destination_rows - 1)
```

It returns false when either inclusive extent is empty. Otherwise:

```text
origin_x = minimum_x
origin_y = minimum_y
warped_columns = maximum_x - minimum_x + 1
warped_rows = maximum_y - minimum_y + 1
```

The transform copied for sampling is made crop-local with wrapped dword
subtractions:

```text
adjusted[2] = transform[2] - origin_x * 0x100
adjusted[5] = transform[5] - origin_y * 0x100
```

The other four words are unchanged. The first output is always allocated on a
successful crop. The second output is allocated and warped only when both its
source and output-pointer arguments are nonnull. Each output is initialized to
`0xff` before `FUN_180068bb0` runs.

## Failure And Publication

An empty clamped rectangle returns false before publishing crop origin or an
output matrix. A zero inverse determinant is not a failure here:
`FUN_180068bb0` is void and applies its determinant-zero coefficient state.
Callers must not describe singularity as a `FUN_18006f390` rejection.
