## Recovered Behavior

The encoder emits the outer `87/86` framing and 13 tagged header values, packs
each feature through `FUN_180040a70`, emits selected relations and metadata tag
`93`, then calls `FUN_18003f290` with live template `+0x87e8`. It calculates the
CRC only after every payload byte has been written.

The exact envelope/header offsets, graph fields, tail blocks, size formula, and
CRC domain are maintained in `../OUTER-TEMPLATE-CODEC.md`. In particular, the
fixed header order is `81,98,9a,9b,91,97,92,9e,9f,9c,9d,fa,fb`. Tags `9e` and
`9f` are distinct: `9e` is the maximum of live `+0x14` and all feature record
counts, while `9f` copies live `+0x18`. Natural type-12 objects carry `150` in
both.

The order vector is therefore gallery-owned live-template state. It is not
derived by the serializer from feature order, relations, metadata, or the live
probe. Sequence-2 tag-`a1` data begins at packed offset `104460`; its eight order
differences cause only outer CRC bytes `1..4` in addition.

The independent audit parses the same order from original, v1, v2, fresh-prefix,
and repeat artifacts despite different anti-fake payload hashes. All entries are
the permutation `0..8`; no pointer or one-past anti-fake value enters this
serializer boundary.

For production type 12, the relation encoder is the branch at
`0x18003ec77..0x18003eda5`. It runs only when graph-established
`template+0x87e4 > 0`, reads the live reference at `+0x87d8`, and visits every
feature index in ascending order except the reference. Pair `(i,j)` uses matrix
slot `feature[max(i,j)].b6 + min(i,j)`. A relation is emitted exactly when its
leading dword is nonnegative; `-1` is omitted, while zero is serialized
regardless of whether the six-word affine is identity. The record is copied in
canonical higher-index-to-lower-index direction without serializer inversion. Packed
tag `e3` is the matrix slot, not either endpoint.

Thus type 12 serializes a reference-centered star, not the complete triangular
matrix and not evidence relation count. Packing order is feature-index traversal
order. With canonical type-12 `b6` row bases, this also produces strictly
increasing packed `e3` slots even when the reference is not zero. With at most
50 features, this projection emits at most 49 of the 1,225 logical matrix slots.
The `FUN_180079ef0` mask branch belongs only to types `9`, `10`, `17`, and `18`.

## Cache-Queue Packing Boundary

The fixed header writes live `+0x8e00` as tag `0xfa` and `+0x8e04` as tag
`0xfb`. The encoder never reads `+0x8d10` or `+0x8db0`; queued feature bodies,
occupancy, ranks, and traversal position are omitted. A controlled state-0
template packed with two occupied entries re-unpacks as state 0 with 20 owners
and all ranks `-1`.

For profile-9/type-12 this is safe because adapter update finalization deletes
all cached candidate handles after the current identify/study transaction. The
queue contract is transient within one live candidate object.

## Exact Scalar Layout

The encoder writes configured maximum from live `+0x20` as fixed header tag
`97` and current count from `+0x1c` as tag `91`. It independently writes raw
queue state/counter `+0x8e00/+0x8e04` as fixed tags `fa/fb` at offsets
`0x41/0x46`. No capacity predicate is serialized as a distinct word.

After features and the selected type-12 relation star, tag `93` contains raw
`f2/f3/f4/f5` from live `+0x87d8/+0x87dc/+0x87e0/+0x87e4`. Their tag offsets
relative to `93` are `+5/+10/+15/+20`; each value follows immediately as little-
endian `u32`. Only `f2/f5` affect type-12 graph behavior. The codec preserves
opaque `f3/f4` exactly.

Unit-6 controls prove that `fa`, `fb`, maximum/count, `f2`, and `f5` can all be
varied independently. The DLL also packs noncanonical queue state 2 and graph
flag 2; that permissiveness is unsafe input behavior, not a native compatibility
requirement.

The native unit-6 migration is complete. `GoodixMilanTemplateMetadata` exposes
explicit queue state/counter and graph reference/companions/established fields;
the serializer emits the same raw values at the same tags. Two-round-trip valid
fixture comparisons and the official capacity transition have zero byte
differences.
