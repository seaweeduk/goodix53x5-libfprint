## Behavior

- For packed subtype 12, the input live frame and setup plane have already been
  scaled by three in `FUN_1800668f0`.
- The production specialized branch computes each source sample as
  `max(scaled_setup - scaled_live - 0x2ffd, 0)`. Since the setup plane contains
  `normalized_setup + 7095`, this is exactly
  `max(9000 + 3 * (normalized_setup - live), 0)`.
- The clamp applies to the complete signed-baseline expression. It is not
  `9000 + 3 * max(setup - live, 0)` and not
  `9000 + 3 * max(live - setup, 0)`.
- The remainder selects update admission, derives gain maps, applies Q13 map
  combinations, and conditionally evolves persistent calibration state.
- Profile-9 admission is initially tested at 80%, but packed subtype 12
  overrides it with the strict test `admitted_mask_pixels * 10 >
  pixel_count * 9`. The admitted count comes from the `FUN_18006a4c0` mask
  structure before later rendering-mask hole fill.
- A non-admitted subtype-12 frame still uses the signed-baseline source above.
  Admission controls frame-derived gain creation and persistent-map evolution;
  it does not fall back to generic `max(setup - live, 0)` rendering. The
  temporary gain starts at Q13 unity, but the common subtype-12 tail still
  combines it with the existing application and auxiliary gain maps before the
  caller renders the working frame.
- Admitted and non-admitted subtype-12 frames share the same primary-divisor
  tail. The persistent ready flag is updated before that tail: update state zero
  with update counter strictly greater than 5 sets it, while update state
  strictly greater than 14 clears it. When ready is clear, the tail computes
  `round(round(temporary_gain * application_gain / 8192) *
  auxiliary_gain / 8192)` with a rounding step after each product. When ready is
  set, it computes only
  `round(temporary_gain * application_gain / 8192)`.
- The admission predicate does not own the ready flag. Admission controls the
  frame-derived temporary gain and map evolution; ready controls which
  persistent maps the shared tail applies. This distinction is reached by both
  production subtype-12 branches.
- The ready pointer is descriptor slot 5. `FUN_1800668f0` always fills that slot
  with global RVA `0x1efbfc`; the only direct xrefs to the global are descriptor
  construction at `0x180066a65` and `0x180066a6c`. No generation initializer,
  profile initializer, exported entry point, or teardown writes the global.
  It is zero-initialized by PE loading, then survives calibration generation
  replacement and admitted/rejected calls until DLL unload/process exit.
- Admitted subtype-12 frames pass the ratio plane produced by `FUN_180063a80`
  to `FUN_180067050`. Its update covers every sample, including the outer and
  second-from-edge columns.
