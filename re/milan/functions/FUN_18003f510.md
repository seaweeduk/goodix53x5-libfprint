## Recovered Behavior

The helper starts from fixed header, metadata, and 0x535-byte tail costs, adds
every packed feature size, then adds 45 bytes per relation selected by the
template-family relation policy. The tail cost is fixed and does not depend on
feature count or the number of defined order entries.

For type 12 the exact result is
`1433 + sum(packed_feature_sizes) + 45*relation_count`: 75 fixed envelope/header
bytes, 25 graph bytes, and the 1,333-byte tag-`94` tail. The outer payload-length
word is the result minus 10. See `../OUTER-TEMPLATE-CODEC.md`.

For type 12, its relation count loop is structurally identical to
`FUN_18003eaf0`: when `+0x87e4 > 0`, it visits the live reference star and adds
45 only for slots with `leading>=0`. This guarantees size/pack agreement for
zero-leading and sentinel slots without consulting recognition evidence. The
generic bound is 49 records for 50 features; production profile-9 prints are
limited to 40 features and therefore 39 records.

This establishes that sequence-2 order correction changes values only, not the
105,783-byte packed size.
