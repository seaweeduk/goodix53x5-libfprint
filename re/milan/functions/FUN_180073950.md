## Behavior

For each row, complete groups of eight source bytes become one output byte.
Source element zero is output bit zero and source element seven is output bit
seven. A partial final group is packed into the low bits. Output row width is
`ceil(input_width / 8)`.

At `0x180073a25..0x180073a55`, each partial final byte and its accumulator are
explicitly zeroed before the remaining source elements are shifted into it.
For binary source pixels and profile-9 width 52, each row has seven bytes with
the upper four bits of the last byte zero, including when an existing output
matrix is reused. Consequently the row-padding bits contribute nothing to the
whole-buffer popcounts in `FUN_180046780` and `FUN_180047120`.

The type-12 normalization caller materializes the source through
`FUN_1800721a0(feature+0x28,1,88,104)`. That decoder reads the inline mask as a
continuous LSB-first `26*22` bit plane and repeats each decoded bit across a
`2*2` block. This function then packs the resulting `52*44` plane into 44 rows
of seven bytes (308 bytes total). The four unused high bits of the 72-byte inline
mask are outside the `26*22` domain. These are distinct from the four row-padding
bits in each byte at offset `7*y+6` of the cached matrix.

`FUN_180047120` creates this cache only when feature `+0x140` is null. Repeated
normalization reuses the unchanged cache and subtracts footprints from a separate
clone; it does not repack or destructively update the cached input mask. See
`FUN_180047120.md` and `FUN_180072600.md`.

Instruction anchors are the unrolled eight-source-byte loop at `0x1800739d0`,
the partial-byte loop near `0x180073a40`, and the cache-presence branch at
`FUN_180047120:0x1800471db..0x1800471f5`.
