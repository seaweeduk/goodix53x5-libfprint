## Behavior

For each row, complete groups of eight source bytes become one output byte.
Source element zero is output bit zero and source element seven is output bit
seven. A partial final group is packed into the low bits. Output row width is
`ceil(input_width / 8)`.

At `0x180073a25..0x180073a55`, each partial final byte and its accumulator are
explicitly zeroed before the remaining source elements are shifted into it.
For binary source pixels and profile-9 width 52, each row has seven bytes with
the upper four bits of the last byte zero, including when an existing output
matrix is reused. Consequently the row-padding bits contribute nothing to the
whole-buffer popcounts in `FUN_180046780` and `FUN_180047120`.

Evidence is the unrolled eight-source-byte loop at `0x1800739d0` and the
partial-byte loop near `0x180073a40`.
