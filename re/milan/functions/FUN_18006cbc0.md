# FUN_18006cbc0

## Identity

- Binary: `GoodixEngineAdapter.dll` 2.0.310.900.
- Address/body: `0x18006cbc0..0x18006cd26`, profile-aware pre-contrast
  transform.

## Call Graph

- Callers: `FUN_18006b510` and `FUN_18006de90`.
- Direct substantive callees: `FUN_180065dd0`, `FUN_180065bf0`, and
  `FUN_18007be70`; allocation, copy, and release helpers manage a temporary
  16-bit image.

## Behavior

- Starts by copying the incoming 16-bit working frame.
- Packed subtype 12 is selected by bit 12 of mask `0x473912`; that branch clears
  the destination and applies `FUN_180065dd0` followed by `FUN_180065bf0`.
- `FUN_180065dd0` uses masked integral sums and counts over the clipped
  radius-five square. For an admitted center it rounds the neighborhood mean
  by adding half the admitted count before division, subtracts that mean from
  the source, adds 3000, clamps negative results to zero, and stores a 16-bit
  value. An excluded center is assigned 3000. The first row participates in
  this transform with clipped neighborhoods; it is not metadata storage here.
- `FUN_180065bf0` snapshots the complete 16-bit plane, then rewrites only
  non-border pixels using the separable 3-by-3 weights `1,2,1`, rounding with
  `+8` before shifting right four. The outer rows and columns retain their
  incoming recentered values at this stage; this is not an edge-copy operation
  and does not establish equality between adjacent first-row samples.
- When chip-info bit 2 is clear, as in production profile 9, it then allocates a
  two-byte image and applies `FUN_18007be70` with operation selector 10 before
  copying the result back.
- This function transforms the auto-calibration working frame before the
  min/max contrast renderer. It does not choose setup/live polarity.
