## Behavior

Parsed scalar index 6 is packed tag `bb` and live feature dword `+0x128`.
This function is its authoritative producer. It first ensures every feature has
the derived packed-bit mask at `+0x140`, then processes features in ascending
index order:

```text
effective_rows = rows
effective_columns = columns
if half_resolution:
    effective_rows >>= 1
    effective_columns >>= 1

for feature i:
    feature[i].overlap_count = 0
    feature[i].bb = effective_rows * effective_columns
    if feature[i].b5 != 0:
        residual = clone(feature[i].mask)
        for feature j in ascending index order:
            if j != i and feature[j].b5 != 0:
                transform j's footprint into i's coordinates
                area = build clipped intervals and clear them from residual
                if half_resolution:
                    area *= 4
                if area * 100 > rows * columns * 40:
                    feature[i].overlap_count++
        feature[i].bb = popcount(residual)
        if feature[i].bb < 20:
            feature[i].bb = 0
```

Thus inactive features receive the reduced-domain area. Production geometry is
`(88 >> 1) * (104 >> 1) = 2288`. Active features receive their residual unique
mask weight after every other active transformed footprint has been removed.
The subtraction is destructive and ordered, but each feature starts from its
own fresh mask clone. Optional `c7` at `+0x150` is never read.

For active feature `i`, it obtains the reference transform from slot
`feature[max(i,reference)].b6 + min(i,reference)`. If `i<reference`, it inverts
the canonical stored transform; if `i>reference`, it copies it directly. It then
composes through other active reference edges for overlap accounting. The
function reads but does not change relation records, their leading values,
feature `b6`, live reference `+0x87d8`, or graph-established `+0x87e4`.
