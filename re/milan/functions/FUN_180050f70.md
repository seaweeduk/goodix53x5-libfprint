## Input And Output State

The histogram has 256 signed 32-bit weights. The companion state is:

```text
+0x00 int64 total_weight
+0x08 int32 mode_bin
+0x0c int16 range
+0x0e int16 minimum
+0x10 int32 sample_count
```

The output state retains `sample_count`, replaces the range/minimum and total,
and records the earliest maximum-weight output bin.

## Exact Algorithm

1. Scan cumulative input weight from bin 0. The low bin is the first bin at or
   above `floor(total_weight * 5 / 1000)`. The high bin is the first bin at or
   above `floor(total_weight * 995 / 1000)`.
2. Map them without rounding:
   `low = minimum + range * low_bin / 255` and
   `high = minimum + range * high_bin / 255`.
3. Clear the output histogram. Set output minimum to `low` and output range to
   the signed-16 difference `high - low`.
4. Only when that range is positive, admit masked source samples strictly
   between `low` and `high`. For each admitted sample:

```text
scaled = (sample - low) * 255
bin = scaled / clipped_range
remainder = scaled - bin * clipped_range
out[bin] += clipped_range - remainder
if bin < 255: out[bin + 1] += remainder
```

5. Sum all output weights and select the earliest bin with a strictly larger
   weight than the previous maximum.

The strict endpoint exclusion and lack of `+128` in the clipping-bound mapping
are significant.
