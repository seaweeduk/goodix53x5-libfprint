alias of live session used count `+0x0a`. At `0x180032a7c..0x180032a95`, a value
equal to context required count `+0x8a` is reset to zero for completed-session
rollover. The function then passes `&DAT_1801ce1a8` to `FUN_18002d4b0` at

## Suppression Counters

`FUN_180032750` resets process-global unsigned dword counters
`DAT_1801ce1b0` (bad-record count) and `DAT_1801ce1b4` (consecutive-bad count)
to zero at enrollment creation (`0x180032809..0x180032813`). Before each
insertion, this function passes suppression byte one to `FUN_18002d4b0` when
unsigned bad-record count is at least 5 or unsigned consecutive-bad count is at
least 3; otherwise it passes zero (`0x180032a65..0x180032a7c`). Suppression
bypasses adapter rollback but does not bypass insertion.

After adapter status `0x8008`, retry publication and counter advancement test:

```text
bad_record_count < 5
bad_continue_count < 3
synchronized_pre_count > 2
```

The conjunction is `0x180032cac..0x180032cd0`. A real policy-generated
`0x8008` already proves suppression was false and synchronized pre-count was
greater than 2, so all three tests necessarily pass. Raw reject detail is then
selected from the pre-increment unsigned bad-record count modulo four as
`0 -> 2`, `1 -> 4`, `2 -> 1`, and `3 -> 3`, then both counters increment once
at `0x180032cd6..0x180032d8d`. The increments are ordinary wrapping dword
increments, but the preceding unsigned gates allow this path to raise the
counters only to their boundary values 5 and 3; saturation is by gating, not by
clamping.

Raw reject detail at context `+0x120` is cleared before every insertion
(`0x180032a56..0x180032a5b`). Adapter status `0x8010` writes raw detail 10;
adapter status `0x8009` leaves detail zero. Adapter success, status `0x8009` or
`0x8010`, transport failure, and unrecognized adapter failure clear only the
consecutive-bad counter, and only while its unsigned value is below 3. Once it
has reached 3 it remains 3, keeping suppression active. The bad-record counter
is never cleared here after enrollment creation.
