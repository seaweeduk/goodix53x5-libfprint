## Recovered Behavior

uses feature `+0x158` as its destination scratch plane. The defined plane size
is the width times height of the caller's first matrix argument, which is the
same `52x44` geometry as feature matrix `+0x08` on the production profile-9
path: exactly 2,288 bytes.

It allocates three temporary planes of that size, clears two, derives binary and
class planes, updates extraction-global classification history, copies or
downsamples one complete defined plane into `feature+0x158`, calls
`FUN_180073fd0`, and frees all three temporaries. It never initializes or reads
bytes after that width-times-height destination boundary.

dimensions before this call. Therefore the physical allocation can contain
untouched allocator residue after the first 2,288 bytes. Those trailing bytes
are not a defined feature plane, are not serialized, and must not be included in
a pointer-normalized matcher-input snapshot.
