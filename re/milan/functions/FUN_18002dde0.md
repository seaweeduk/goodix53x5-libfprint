# FUN_18002dde0

## Audit Scope

Production adapter caller of `identifytemplate` at `0x1800024f0`. This note was
created before first Ghidra inspection during the independent methodology audit.

## Questions

- What five arguments does the adapter pass?
- Is this path used for a driver operation distinct from image identification?

## Audit Findings

- The adapter uses this path to compare a candidate enrollment template with
  the current enrollment template, not for normal image verification.
- It passes unpacked probe and enrollment templates, an opaque third value, the
  configured anti-fake mode, and an output feature index.
- The old oracle's one-image enrollment-generated probe template exercised this
  export ABI, but it was not the retained live `identifyImage` probe and must
  not be supplied to native study.
- The corrected identify-only oracle serializes the retained live probe before
  `templateStudy`; template-to-template identification is no longer part of the
  normal identify replay path.
