## Copy Contract

The helper copies bounded records, clones feature matrices and the derived
mask, copies quality/coverage, and deep-copies the `0x1abc` anti-fake object
when present. It targets an existing preallocated feature slot for actions
2, 3, and 4 rather than claiming a new append slot.

The live template maximum is passed to `FUN_180037690`. A probe at or below
that bound is copied completely with its partition boundary `b7/+0x118`.
Above the bound, records are ranked by their live `+0x08` word through the
compact ranking helper at `0x18006eed0`; only bounded winners are copied, and
`FUN_180037480` regenerates partition state. Type-12 copying then clears live
record spans `+0x24..+0x27` and `+0x30..+0x37`, which are absent from the
32-byte packed record form. Successful type-12 unpack sets the effective
record capacity to 150, and ordinary extraction emits at most 150 records.

The selective scalar boundary is:

- Probe quality/coverage replace target `+0x11c/+0x120`.
- At `0x18004594e..0x180045961`, probe `c0/+0x14c` replaces target `c0` only
  when nonzero and odd; zero or even values leave the target unchanged.
- Optional `c7/+0x150` is neither read nor written, so the existing target's
  value survives and probe `c7` is not imported.

Both ordinary extraction export callers pass a null auxiliary input to
`FUN_18004ae70`, which writes probe `+0x14c=0`. This does not weaken the
generic nonzero-odd copy predicate.

## Anti-Fake Ownership

At `0x1800459a8..0x180045a33`, the anti-fake copy transfers 53 blocks of
128 bytes followed by 60 bytes, exactly `0x1abc` bytes. It includes all 2,000
packed-mask bytes at anti-fake `+0x12dc`; there is no mask regeneration,
coordinate transformation, clipping, or normalization in this copy. The source
is the live probe object after the caller's four matched-owned registration
dword assignments. The allocator-dependent feature-boundary read described in
`FUN_1800392f0.md` therefore remains represented in any affected copied mask.

## Failure Behavior

The helper is void and mutates the live gallery in place. Record, optional
matrix, and anti-fake allocations are not checked before their returned
pointers are stored or consumed. There is no recoverable mutation status or
rollback. A late allocation failure can occur after counter increments and
other target writes, as a process fault rather than a clean action-zero result.
