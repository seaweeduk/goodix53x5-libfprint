
arm. This leaf does not initialize context confidence. It returns `raw` when
any predicate below is true, in short-circuit order, and `128` otherwise:

```text

quality > 18 && context_confidence > 62
quality > 19 && context_confidence > 50
quality > 17 && ((context_confidence > 40 && context_count > 7) ||
                 context_count > 8)
raw > 230 && quality > 16
```

`40/41/50/51/62/63`, and quality `16..20/23/24` therefore have exactly the
boundaries shown. If `valid_count == 0`, the leaf immediately returns `128` and
does not dereference the weights array or write `+0x44`. It does load the
weights pointer from context `+0x30` before testing valid count, so a null
context faults while a null weights pointer is tolerated only on this zero
path. Arbitrary negative or inconsistent scalar arguments are trusted; they can
produce wrapped results or a hardware division exception. The production caller
