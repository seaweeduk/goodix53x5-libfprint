## Recovered Behavior

It refines an extrema location in x/y/scale for at most five derivative/solve
attempts (`0x18004c650..0x18004c80b`). `FUN_180048c60` produces signed-16
gradient and Hessian terms; `FUN_18004bed0` solves `H * offset = -gradient` in
Q12. A solve has converged only when all three absolute offsets are strictly
below `0x800`. Otherwise each coordinate moves by nearest integer with
half-away-from-zero behavior at Q12 bit `0x800`. The moved scale must remain
`1..3`, and moved x/y must remain in the one-pixel interior. A fifth
non-converged solve fails after applying and publishing that final movement to
the caller's candidate.

On convergence, subtype 12 uses absolute contrast
`abs(center*0x4000 + dot(gradient,offset))` and requires it to be at least
`0x1478000` (`0x18004c827..0x18004c8b8`). It stores strength as contrast shifted
right 12. For the spatial `2x2` Hessian it requires determinant `> 0` and the
strict edge test
`determinant * 41^2 > 40 * trace^2` at
`0x18004c8ea..0x18004c913`. Refined x/y are `(integer*0x1000 + offset) >> 4`
truncated to signed 16-bit Q8; curvature is
`trace^2*0x400/determinant`. Scale is
`exp2_q16(((scale*0x1000 + offset_s)*0x10)/3) * 0x13333 >> 16`, where signed
division truncates toward zero and `FUN_180074890` implements the fixed
threshold-table approximation at `0x180074890..0x180074933`. That leaf takes
the wrapping signed-32 absolute magnitude, shifts the Q16 base `0x10000` by the
integer part, greedily consumes thresholds
`[95c0,526a,2b80,1664,0b5d,05ba,02e0,0171,00b8,005c,002e,0017,000c,0006,0003,0001]`,
and adds `result >> (bit+1)` for each consumed threshold. Positive inputs return
the low 32 bits; zero/negative inputs return unsigned `0x100000000/result`.
Accepted type-12 refinement constrains the exponent to `10928..76453` and the
emitted scale value to `88274..176532`.

The caller tests the converged integer `(x,y)`, not refined Q8 coordinates, for
collisions. Current owner: `feature/extrema.c:goodix_milan_feature_refine_extremum`;
collision ownership is in `feature/materialization.c`.

## Mutation And Solver Contract

The candidate is 24 bytes: signed-32 x/y/scale/strength at offsets 0/4/8/12,
signed-16 Q8 x/y at 16/18, and signed-32 scale value at 20. Curvature is a
separate 32-bit output. Derivative failure and contrast rejection do not write
new candidate fields; any integer movement published by an earlier iteration
remains. Movement writes all three integer coordinates before testing scale,
x, y, and the five-attempt limit (`0x18004c7bd..0x18004c80b`).

Strength is written at `0x18004c8c7` before determinant and edge-ratio checks.
An edge rejection therefore retains the new strength but does not write Q8
coordinates, curvature, or scale value. Success writes Q8 coordinates, then
curvature, then scale value. The input scale planes remain unchanged.

offsets, rather than rejecting, so this owner proceeds to contrast and spatial
edge admission. The positive saturation offset `0x00ffffff` takes the movement
path rather than the convergence path. See [offset solving](FUN_18004bed0.md)
for signed bit lengths, arithmetic rescaling, cofactors, and division.
