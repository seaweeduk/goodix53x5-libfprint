## Recovered Behavior

It builds a one-pixel-padded signed-16 integral image while counting global zero
pixels. It initializes the caller's global count and complete local-count output
to zero, fills the integral image and global count in one source traversal, and
then writes clipped square-window zero counts for every source pixel when at
least one zero exists. It does not apply the filter's threshold of 50;
`FUN_18004db10:0x18004dbc9..0x18004dbd8` applies that threshold after this helper
returns. The neighborhood radius is caller-selected. At the profile-9/type-12
`FUN_18004db10` call, decoded high classes below four use radius two; high
classes four or five use radius five. Type 11 substitutes radius seven in the
latter branch, but that path is outside profile 9.
