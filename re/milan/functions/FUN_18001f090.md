# FUN_18001f090

## Identity

- Binary: `GoodixEngineAdapter.dll` 2.0.310.900
- Address: `0x18001f090`
- Logged name: `EngineAdapterClearContext`
- Role: clear per-operation engine state while retaining attached preprocessor
  calibration.

## Interface And Calls

`WbioQueryEngineInterface` publishes this function in the
`EngineAdapterClearContext` slot immediately after attach and detach. It has no
static in-DLL caller because Windows Biometric Framework invokes the callback
through the exported interface table.

Microsoft's `PIBIO_ENGINE_CLEAR_CONTEXT_FN` contract defines this callback as
preparation of the existing biometric-unit pipeline for a new operation. The
engine context is reusable: clear-context reinitializes it but does not remove
it from the pipeline. This distinguishes an ordinary operation boundary from
`EngineAdapterDetach`, which runs only when the adapter is removed from the
pipeline.

The function clears operation mode at engine context `+0x08`, calls
`FUN_180031330` (`_ClearContext_Unify`), and clears match byte `+0x11c`.
`FUN_180031330` delegates to `FUN_18002b960` (`_ClearContext_E`), which finishes
an active enrollment object and frees its temporary packed buffer.

## Retained State

This path does not clear engine-context initialized byte `+0x7c`, call
`preprocessor_exit`, or clear the global preprocessing calibration workspace.
Those are attachment-lifetime resources; adapter detach reaches
`preprocessor_exit` through `FUN_180030f40`.

Therefore an operation boundary, including a no-match followed by another
Windows Hello attempt, does not itself reacquire or reinitialize the reference.
The next sample reinitializes only when the hardware's one-shot base-refresh
marker is one, or when a detach/new attach has reset the engine context.

Confidence: high from interface-table order and the complete decompiled
`FUN_18001f090 -> FUN_180031330 -> FUN_18002b960` chain, plus the published WBF
clear-context contract:
<https://learn.microsoft.com/en-us/windows/win32/api/winbio_adapter/nc-winbio_adapter-pibio_engine_clear_context_fn>.
