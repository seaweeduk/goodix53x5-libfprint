## Matrix And Partition Contract

The function consumes enrolled and probe feature objects plus the caller-owned
`180x180` descriptor distance matrix produced by the primary path. Probes own
the candidate rows. A leading probe considers enrolled `[0,e_split)` and a
trailing probe considers `[e_split,e_count)`; no candidate crosses the stored
physical partition boundary. Each candidate distance is the unsigned byte at
`enrolled_index * 180 + probe_index`.

The physical traversal is enrolled-outer/probe-inner in each rectangle
(`0x180079100..0x180079217`), reducing into probe-indexed arrays. Thus each
probe observes enrolled indices in ascending order. Transposing that traversal
must preserve this per-probe order and must still consume `D(enrolled,probe)`.

Best and second distances initialize to 192 and best indices to `-1`. Updates
are strict, preserving the earlier enrolled record on best and second ties.
An equal best becomes second when the previous second was larger.
Empty partitions and matrix values that do not improve 192 leave the probe
unset. The partitioned scan is at `0x1800790d8..0x180079219`.
