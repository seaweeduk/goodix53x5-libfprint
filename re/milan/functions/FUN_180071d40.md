### Core helper details

`FUN_1800721a0` expands the packed one-bit bitmap before warping. Packed rows
are based on `(width + 3) >> 2` and `(height + 3) >> 2`; mode zero replicates
each packed sample to a 4x4 area, while mode one replicates to 2x2. Trailing
columns use the final packed byte. This expansion order is least-significant
bit first.

`FUN_18006f390`, called by `FUN_1800717e0`, transforms all four image corners,
sorts the resulting coordinates, clamps the destination rectangle, allocates
cropped destination matrices, and records crop origin in context words `[6]`
and `[7]`.

`FUN_180068bb0` performs the actual inverse affine warp. It computes inverse
coefficients in Q10, fills out-of-bounds pixels with the destination's initial
byte, uses bilinear interpolation for four valid neighbors, and averages only
the valid neighbors on a boundary. The bilinear result adds `0x80000` before
shifting by 20.

`FUN_180073540` performs class partitioning after the first input is warped. For
each pixel accepted by both validity masks, it increments:

```text
class_index = direct_second + warped_first * 2
```

where both values must be below 2. Thus internal class order is exactly
`00,01,10,11` when written as `(warped_first,direct_second)`. It optionally creates a mismatch mask for
pixels where source and target differ, then applies two morphology helpers.

`FUN_18006f390` passes an adjusted transform to the warp: after calculating
the clamped crop origin, it subtracts `origin_x * 256` and `origin_y * 256`
from the two translation components. Fixtures with nonzero origins prove this
adjustment is required before inverse sampling.

## FUN_18005a3c0 Ownership Closure

The complete caller audit proves that count is part of overlap-call ownership.
Primary overlap uses primary affine/count and alternate overlap uses local
alternate affine/count. Ranking copies the winning call's already-produced
score/detail/coverage; it does not recompute the winning affine with the other
count. Native currently violates this for larger-count primary rank winners and
would also violate it for lower-count alternate rank winners if rank alone were
moved without carrying the complete call result. This closes the target-facing
ownership contract; unresolved internal descriptor names are nonsemantic only.
