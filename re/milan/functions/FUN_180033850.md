# FUN_180033850

## Audit Scope

Caller of the production identification adapter wrapper `FUN_18002e360`. This
note was created before first Ghidra decompilation during the scoped production
argument provenance audit.

## Questions

- Which object is forwarded as the `identifyImage` auxiliary pointer?
- Which context/configuration fields supply recognition mode and anti-fake mode?

## Audit Findings

- Engine-context `+0x198` is forwarded as the identify auxiliary pointer.
- Recognition mode is booleanized from context `+0x94`; production attach
  initializes that field to `1`.
- Anti-fake mode is the 32-bit context field `+0x1c4`, copied from dynamic
  configuration byte `+0x423`. The compiled `IsOpenAntiFake` default is `1`.
