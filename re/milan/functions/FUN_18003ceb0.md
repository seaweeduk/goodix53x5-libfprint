# FUN_18003ceb0

- Binary: `GoodixEngineAdapter.dll` 2.0.310.900.
- Entry/body: `0x18003ceb0..0x18003d19e`; sole caller `FUN_1800392f0`.

## Recovered Behavior

The function partitions the residual/mask into centered fixed-size blocks,
retains each block's maximum when its mask is fully active, and returns a Q12
coefficient of variation over retained maxima. Profile 9 supplies block size 12
and stores the result at anti-fake `+0x12cc`. It does not own candidate records
or count.

Block counts are `rows / block_size - 1` and `columns / block_size - 1`;
origins are `(dimension - block_count * block_size) / 2`. Thus `88x108` with
size 12 visits six by eight blocks, starting at row 8/column 6. Each complete
12x12 block contributes its unsigned-word maximum only if **every** mask byte
is nonzero. An invalid block is still fully scanned. Temporary maxima and
validity arrays hold 48 words and 48 bytes respectively and are freed before
return. Inputs are not mutated; allocation results are unchecked.

Each retained `uint16_t` maximum is squared with dword `IMUL`; the square sum
wraps at `0x18003d122..0x18003d125`. The rounded mean-square numerator is the
wrapping dword addition at `0x18003d13d`, reinterpreted signed, then divided by
positive `valid_count` with signed truncation toward zero. Variance subtraction
also wraps and a negative signed result clamps to zero.

The mean is `(sum + (valid_count >> 1)) / valid_count`; both mean and
mean-square start at zero when no block is valid. After signed-negative
variance clamping, `FUN_180074940` takes the integer square root. The returned
score is `root * 4096` when mean is zero, otherwise
`(root * 4096 + (mean >> 1)) / mean`. With 48 unsigned-word maxima the mean sum
fits a positive signed dword; the variance is clamped to a nonnegative signed
dword before the square root. No valid blocks and all-zero valid blocks both
return zero.

`FUN_180074940` returns its unsigned input directly for 0/1. Otherwise it starts
root 0, bit `0x8000`, shift 15; at each descending bit it forms
`candidate=(bit+2*root)<<shift`, accepts when `candidate <= remainder`, adds
the bit to root and subtracts candidate, then shifts the bit right. All
operations are unsigned dwords. This supplies the integer-root contract used
by the final Q12 scaling.
