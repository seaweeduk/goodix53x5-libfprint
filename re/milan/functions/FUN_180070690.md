## Behavior

The helper normalizes a byte-matrix width to a multiple of eight while
preserving its row count and element type. With its second argument zero, a
non-multiple width is rounded down and the source is centered horizontally by
skipping half the discarded columns. With a nonzero second argument it rounds
up and edge-pads instead.

The production subtype-12 extraction call passes zero because the source width
is not `118`. For a `108x88` source, the function allocates `104x88` and copies
each row from source column `2` through `105`.
