# FUN_180073090

## Identity

- Binary: `GoodixEngineAdapter.dll` 2.0.310.900.
- Entry/body: `0x180073090..0x1800731c4`.
- Role: solve an inclusive integer-index interval for one signed Q8 affine
  coordinate.
- Direct caller: `FUN_180071370`.

## Contract

For signed dword origin `o`, step `s`, source extent `n`, and destination limit
`m`, the helper writes the inclusive index range for the linear coordinate:

```text
0 <= o + i*s <= n*256 - 256
```

For positive and negative `s`, it obtains initial endpoints with signed `IDIV`
and then corrects them one index at a time until the mapped endpoint satisfies
the inclusive lower or upper bound. Endpoint products and additions are dword
operations. Signed division truncates toward zero. Overflow is not detected and
can violate the monotonic linear-coordinate interpretation.

For `s == 0`, an in-range origin returns `[0, m-1]`. An out-of-range constant
coordinate returns the empty sentinel interval
`[0x0fffffff, 0xf0000001]`. The positive and negative branches use the same
sentinels when no valid endpoint survives. `FUN_180071370` intersects and clips
the returned intervals, so a sentinel pair contributes no area.

The helper validates neither output pointer and returns no status. Its only
mutations are the two caller-owned endpoint words.
