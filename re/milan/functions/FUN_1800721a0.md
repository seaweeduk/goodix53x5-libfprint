helper describes the packed source as
`ceil(104/4) x ceil(88/4) = 26x22`, expands its 572 contiguous bits through

```text
(2*x, 2*y)       (2*x+1, 2*y)
(2*x, 2*y+1)     (2*x+1, 2*y+1)
```

within each byte is least-significant first. Rows are not byte-padded. The first

ignored. Thus every one of the 2,288 output bytes is assigned once and no
sentinel from the initial `0xff` fill survives fixed geometry.

`drivers/goodix53x5/milan/feature/mask.c:17-31`. Its fixed `size_t` indices cannot
overflow. The array syntax does not enforce storage at runtime: callers must
supply at least 72 readable input bytes and 2,288 writable output bytes, and the
buffers must not overlap because early output stores could overwrite packed
