## Behavior

- Applies the fixed five-tap Gaussian, asymmetric Sobel passes, half-L1
  gradient magnitude, and a reflected `15x15` box filter.
- Writes the requested mask byte where the filtered gradient is strictly above
  the caller's threshold and zero elsewhere.
- Returns `floor(selected_count * 0x10000 / pixel_count)` with signed-32
  count/numerator/division. Both the 9,504-pixel preprocessing geometry and
  9,152-pixel cropped extraction geometry keep the product in range.
- The profile-9 preprocessing caller uses the primary contrast image, threshold
  `100`, and mask value `255`. `FUN_18006e7f0` uses this generated mask for both
  candidate metrics and correlation; it does not use the valid or profile
  rendering masks for subtype 12.
- Final image quality calls the same filter on the selected 108x88 output at
  threshold `120`. The comparison is strict `filtered > 120`. That caller needs
  the returned raw Q16 coverage and does not request a mask write.
- The profile-9/type-12 extraction call writes byte `1` for every selected
  `104x88` validity position, using write selector `1` and strict threshold
  `110`. Its mask and `FUN_18007eb30` enhancement share the same cropped byte
  input; neither matrix is derived by thresholding the other.

For the final-quality call, the byte image is separably filtered by the fixed
five coefficients, asymmetric Sobel X/Y values are converted to
`floor(abs(x)/2) + floor(abs(y)/2)`, and each reflected 15x15 sum is multiplied
by 291 and shifted right 16. If `S` pixels are strictly above 120, this function
returns `R = floor(S * 65536 / 9504)` and the quality combiner publishes
`floor(R * 100 / 65536)` as coverage. Consequently coverage 4 and 6 correspond
to ordinary nonzero gradient sets, not failed rendering.

## Extraction Mask And Enhanced-Zero Support

The mask is a neighborhood-gradient admission, not a lower bound on the
co-located enhanced intensity. `0x18007e6d9..0x18007e6e9` supplies radii `7,7`
to `FUN_18007d530`; the box conversion truncates `sum * 291 >> 16` before the
strict comparison with `110`. The half-L1 conversion separately halves the
absolute signed Sobel components before adding them. The Gaussian and box
stages use reflected borders; enhancement instead omits out-of-image line taps
and divides by the sum of the retained weights.

In particular, the type-12 producer does not impose a bound of
`zero_enhanced_samples <= (205 * active_samples + 128) >> 8` on the sampled
mask. A concrete same-image construction uses zero-based `(row,column)` in an
otherwise-zero `88x104` byte image:

- set all rows of columns `13,19,25,31,37,43,49,55,61` to `255`;
- additionally set column `32`, rows `40..43`, to `255`;
- set rows `60..79`, columns `80..95`, to `1`.

The actual extraction mask has 46 active even/even samples; 41 corresponding
enhanced samples are zero. The quantile target is 37, so
[FUN_180071260](FUN_180071260.md) returns zero. There are 68 even/even enhanced
samples equal to one outside this mask, and five other positive sampled values.
Consequently [FUN_18006fef0](FUN_18006fef0.md) retains 73 enhanced bitmap bits.
Removing the intensity-one rectangle preserves the 46/41 mask counts and
threshold zero but leaves only five positive bits. Replacing the zero background
with one preserves 46 active samples, makes their zero-bin count zero, and
selects threshold one.

The odd-column line train alone has no selected mask samples. Its localized
four-pixel widening creates above-threshold neighborhood support that includes
many unchanged dark even/even enhancement positions. Thus the mask and
enhancement correlation permits both masked enhanced zeros and independently
retained unmasked enhanced ones.
