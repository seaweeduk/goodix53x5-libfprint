equivalent only for `0 <= feature_orientation < 0x3244`. Both type-12 producers
guarantee that interval: extraction normalizes the selected antipodal peak, and

descriptor-sample helper with an out-of-domain orientation is therefore a
synthetic-valid source difference, not a production-reachable discrepancy.
