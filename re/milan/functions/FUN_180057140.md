## Recovered Behavior

It forms squared column lengths `a*a+c*c` and `b*b+d*d` with wrapping dword
multiply/add and passes those unsigned dwords to floor-sqrt leaf
`FUN_180074940`. Their dword roots are added and divided by two with signed
truncation toward zero. An average length of zero returns without touching
either index array.

Otherwise cosine is `(((d+a)/2)<<8)/average` and sine is
`(((c-b)/2)<<8)/average`: sums/differences, the left shift, and intermediate
storage are dwords; both divisions are signed and truncate toward zero. It calls
`FUN_180074290(sine,cosine)`, which under that leaf's pointer convention returns
`atan2(sine,cosine)`. The signed 16-bit result has one period added only when
negative.

For each slot whose enrolled and probe indices are both nonnegative, it forms
`enrolled_orientation-probe_orientation+affine_angle`. Direct distance and the
same value plus `0x3244` are each normalized by at most one negative add and one
strictly-greater-than-period subtraction, then folded with the strict comparison
`period-value < value`. The opposite axis replaces direct only when strictly
smaller; an equal direct/opposite tie remains direct. If the resulting minimum
is strictly greater than `0x506`, both indices become `-1`. Equality `0x506`
is retained and `0x507` is removed.

The orientation period is `0x6488`; the half-period is `0x3244`. The helper does
not alter the affine, residual, or any independent model-valid state.

## Dependency Unit 5 Failure Contract

This helper can reduce an accepted robust model to retained count `0`, `1`, or
`2` without changing the affine or creating estimator failure. Refinement remains
suppressed until retained count exceeds three. Model validity must therefore
survive this filter even when retained count becomes zero.

The helper accepts a signed count and has no explicit capacity check. A
nonpositive count skips the loop after affine-angle construction; a malformed
positive count walks the supplied index arrays. Null feature or affine pointers
fault before the zero-scale decision, while null index arrays fault only on a
positive loop. Production supplies a robust-pre-gated affine with linear
coefficients below 300 in magnitude and at most 42 pairs. The current
implementation matches the DLL on that domain; its wider square-root expression
differs only for malformed large coefficients.
