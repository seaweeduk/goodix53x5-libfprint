## Recovered Behavior

The first output decodes packed bits `0..1`; the second decodes bits `8..10`:

```text
low class:  raw 0,1,2,3         -> 0,2,2,3
high class: raw 0,1,2,3,4,5,6,7 -> 0,1,2,4,5,5,0,0
```

The second mapping follows the intermediate `raw == 0 ? 0 : raw + 4` and the
shared class switch. All shifts, masks, and table boundaries are exact from the
body.

caller. At `FUN_18004ae70:0x18004b590..0x18004b5fa`, embedded-mask presence
selects `FUN_18004db10`, and that original high class selects radius2/mode0
when below4, otherwise radius5/mode1 for type12. The history-promoted high
class packed by `FUN_180048260` does not replace this filter argument.
The resulting packed scalar is stored at feature `+0x150` only after filtering
and inline/rescue-mask production. Without an auxiliary pointer, classification
is skipped and this packed scalar remains the raw image-decoder value.
With the pointer, `FUN_180073820` writes `promoted_high*256 + decoded_low`;
it does not invert the decoder mapping. Raw image high3 therefore decodes to4,
and a classification result retaining that4 is stored as high4, which a later
matcher decode maps to5. The original entry class, published packed scalar,
and later matcher-decoded class have distinct meanings.
