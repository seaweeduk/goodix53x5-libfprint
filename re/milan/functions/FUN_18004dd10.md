## Exact Contract

The function copies an input byte mask to an output mask, then independently
processes every row and every column. From each of the four ends it clears the
first `remove_count` nonzero samples encountered. Zero samples do not consume
the removal budget. The four passes observe the original input when deciding
which positions consume a budget, so earlier output clears do not alter later
admission.

For profile 9/type 12, dimensions are 88 rows by 108 columns and
`remove_count = 8`. This is already implemented by
`milan_profile9_erode_valid()` in Linux.
