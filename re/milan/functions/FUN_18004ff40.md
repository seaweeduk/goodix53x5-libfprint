# FUN_18004ff40

## Identity

- Profile-9 retained broken-level state serializer at
  `0x18004ff40..0x1800501c5`.
- Called at the end of every entered type-12 classifier call.

## Workspace Layout

| Offset | Value |
| --- | --- |
| `+0x26488` | Signature `0x24cc7bf4f728f6f4` |
| `+0x26490` | Version `0x2711` |
| `+0x26494` | Three-plane history count, cap 3 |
| `+0x26498` | Component-age counter, cap 5 |
| `+0x2649c` | Reference/support count, cap 50 |
| `+0x264a0` | 9,504 packed per-pixel words |
| `+0x2aee0` | 44x54 downsampled retained reference |

Packed word bits are history planes at 0..1, 2..3, and 4..5; component age at
6..9; support age at 10..15. Reference downsampling loads four signed 16-bit
values at `(2r,2c)`, `(2r,2c+1)`, `(2r+1,2c)`, `(2r+1,2c+1)`, sums in 32 bits,
and arithmetic-shifts right by two without a rounding bias. The 2,376 resulting
signed words are row-major with 54 columns. Negative sums round toward minus
infinity.

The first argument is a borrowed descriptor: component-age pointer at `+0x00`,
history-plane pointer at `+0x08`, support-age pointer at `+0x10`, signed reference
pointer at `+0x18`, component count at `+0x20`, history count at `+0x24`, support
count at `+0x28`, rows at `+0x2c`, columns at `+0x30`, and version at `+0x34`.
All four pointers must be nonnull and descriptor version must be `0x2711` before
any packet write. The three history-plane source strides are `0x4c90` bytes;
only the first 9,504 bytes of each plane are serialized for 88x108 geometry.
The descriptor, source arrays, and counts are unchanged. Temporary packed-word
and downsample buffers are copied to the second argument's workspace and freed.

Serialization occurs after current broken-level state changes but before the
later feature-extraction history-ring append. A new history-ring entry therefore
appears in the workspace packet on the next classifier call.

The reference ends at packet-relative `+0x5ce8`. The serializer does not write
packet-relative `+0x5ce8..+0x9fff`; calibration save/load still transports those
`0x4318` trailing bytes because the containing block is `0xa000` bytes. No
packet importer read reaches that trailing range.

The packet begins at workspace `+0x26488`, which is the address
`DAT_18023faf8`. `preprocess_save_calidata` copies the containing `0xa000` bytes
to payload `+0x1848c`; `preprocess_load_calidata` restores them to the same
workspace address. The packet is therefore part of official calibration
persistence even though its workspace offset is beyond the payload length.
