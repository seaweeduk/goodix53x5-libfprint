# FUN_18004ff40

## Identity

- Profile-9 retained broken-level state serializer at
  `0x18004ff40..0x1800501c5`.
- Called at the end of every entered type-12 classifier call.

## Workspace Layout

| Offset | Value |
| --- | --- |
| `+0x26488` | Signature `0x24cc7bf4f728f6f4` |
| `+0x26490` | Version `0x2711` |
| `+0x26494` | Three-plane history count, cap 3 |
| `+0x26498` | Component-age counter, cap 5 |
| `+0x2649c` | Reference/support count, cap 50 |
| `+0x264a0` | 9,504 packed per-pixel words |
| `+0x2aee0` | 44x54 downsampled retained reference |

Packed word bits are history planes at 0..1, 2..3, and 4..5; component age at
6..9; support age at 10..15. Reference downsampling is a 2x2 integer sum shifted
right by two.

Serialization occurs after current broken-level state changes but before the
later feature-extraction history-ring append. A new history-ring entry therefore
appears in the workspace packet on the next classifier call.

The packet begins beyond the `0x224b0` bytes exported by the official
calibration save API and is not part of `preprocess_save_calidata` output.
