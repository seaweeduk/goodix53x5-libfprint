## Recovered Behavior

It builds and smooths a 36-bin weighted orientation histogram around a refined
candidate. Smoothing is circular `[1,4,6,4,1]/16`; maximum selection retains
the first bin on ties. Mode 1, used by shipping subtype 12, duplicates each
contribution into its antipodal bin. The resulting symmetry places the first
maximum in bins `0..17`, after which the selected output is changed to
`peak_bin + 18` while retaining the same maximum value. It changes record
payload/orientation but not candidate admission.

Radius Q16 is `(scale_value * 18) >> 2`; it is rounded to the nearest signed
integer with half-away-from-zero behavior and capped at 32. Sigma Q16 is
`(scale_value * 6) >> 2`. `FUN_18004aaf0` fills a symmetric
`(radius+1)^2` unsigned 32-bit weight table from coefficient
`0x800000000000 / sigma^2`, using the exact polynomial and cutoff
`power <= 0x6ee75` reproduced at `feature/materialization.c:18-47`.
That directly relevant leaf is `0x18004aaf0..0x18004ac32`: it visits
`y=0..size-1`, `x=y..size-1`, mirrors each result to `[y,x]` and `[x,y]`, uses
unsigned wrapping 32-bit radius-square/power and polynomial products, emits zero
above the cutoff, and otherwise finishes with unsigned division
`((approximation >> 1) + 0x40000) / approximation`.
Sampling clips to the image interior `1..width-2`, `1..height-2`. Orientation
binning is signed division
`(-36 * orientation + 0x743d4) / 0x6488`; bin 36 maps to zero. Each contribution
is `(uint32_t)(magnitude * weight) >> 8`, accumulated modulo `2^32`.

Raw-bin antipodal addition and circular smoothing at
`0x18004994f..0x180049a9b` are also unsigned 32-bit modulo operations. Strict
maximum updates at `0x180049a9d..0x180049ac7` establish the first-bin tie rule.
Antipodal pair equality survives wrap, so every well-formed type-12 selected
index after the `+18` adjustment remains in `18..35`.

Current source correspondence is
`drivers/goodix53x5/milan/feature/materialization.c:50-123`.
Refinement supplies positive nonzero scale, and the gradient builder supplies
orientations whose computed bins are `0..35`. Zero sigma or a negative bin
requires malformed direct intermediate state; neither implementation returns a
generic error for it. Zero sigma reaches native signed division by zero and the
corresponding source division is undefined. A negative computed bin indexes
before the native/source raw histogram. These are native crash/memory-unsafe
surfaces, but the profile-9/type-12 owner chain excludes both.

The DLL forms both scale products in wrapping signed 32-bit lanes and uses
arithmetic shifts at `0x180049716..0x180049779`. Current source deliberately
casts to unsigned before multiplication and shifting. They are identical for
the accepted type-12 scale range `88274..176532`, which yields radius `6..12`,
but differ for negative or overflowed synthetic scale values. Such values are
not synthetic-valid owner-chain output: native can derive a negative table size
and unsafe loop/index bounds, while source caps the resulting nonnegative radius
at 32. This is intentional safer malformed-input behavior, not a production
defect.
