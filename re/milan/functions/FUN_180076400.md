## Match-Matrix Producer Contract

The helper writes caller-owned `180x180` byte matrices with stride 180. The
distance matrix arrives initialized to `0xff`; the layout matrix arrives zeroed.
For each pair in the supplied half-open rectangle, it computes first-segment
distance over offsets `16..23` with inclusive limit 23, then normal base
`first+second` and shifted base `first-second+64` with inclusive limit 47.
Normal tail terms compare `32..35/40..43` to `32..35/40..43`; shifted terms
compare them to `36..39/48..51`. Both invalid bases leave `0xff/0` untouched.

The lower total is stored as distance. Normal layout one is stored only on a
strictly lower normal total, so a tie selects shifted layout zero. Direct DLL
controls cover first 23/24, bases 47/48, both winners, the strict tie, defaults,
and two disjoint stored-partition rectangles. The exact model and expected full
matrices are under external artifact root `match-matrix-contract-v1/` and are
summarized in `re/milan/MATCH-MATRIX-CONTRACT.md`.
