# FUN_180076400

## Identity and interface

`GoodixEngineAdapter.dll`, `0x180076400..0x180076845`.
Generic segmented descriptor scan used by `FUN_180078a70` for type 12.
Current distance counterpart: `milan_recognition_descriptor_details()`.

Arguments are enrolled records, probe records, range/configuration descriptor,
best/second distances, best/second indices, distance matrix, and layout matrix.
The descriptor's signed dwords `+8/+12` bound enrolled indices, `+16/+20`
bound probe indices, and `+24/+28` supply limits 23/47. Records have stride 56;
matrices have stride 180 and index `enrolled*180 + probe`. No allocation or
status path exists. Reductions and matrices must already be initialized.

## Asymmetric distance and layout

Let `H` count differing bits. With enrolled `e` and probe `p`:

- `a = H(e[16..23],p[16..23])`; reject when `a > 23`.
- `b = H(e[24..31],p[24..31])`.
- Normal base `n = a+b`, shifted base `s = a-b+64`.
- Reject when both bases exceed 47.
- An eligible normal tail is `H(e[32..35],p[32..35]) +
  H(e[40..43],p[40..43])`; an ineligible normal tail is 192.
- An eligible shifted tail is `H(e[32..35],p[36..39]) +
  H(e[40..43],p[48..51])`; an ineligible shifted tail is 192.
- Store the lower total, adding each base to its tail. Store layout one only
  when the normal total is strictly smaller; a tie stores shifted layout zero.

The limits use signed `JG` at `0x1800765b1` and signed comparisons at
`0x18007662d..0x180076644`. Layout uses `SETL` at `0x18007675e`.
The shifted terms keep enrolled/probe operand ownership; transposing iteration
does not authorize evaluating `D(p,e)` instead of `D(e,p)`.

Every admitted total is at most `47+64=111`. Thus it is below the initial
reduction sentinel 192 and fits the matrix byte without truncation. Rejection
does not write either matrix or reductions. With caller defaults `0xff/0`,
the reverse reducer's unsigned 255 cannot improve its 192 sentinel. A
recomputed negative rejection and a native rejected matrix cell therefore
exclude the same candidate.

## Ordered reduction and lifetime

Enrolled indices are the outer loop; probe indices ascend inside each supplied
rectangle. At `0x180076769..0x180076799`, `d < best` shifts old best distance
and index into second, then replaces best. Otherwise `d < second` replaces
second only. Equal best retains the earlier best index but becomes second if
second was larger; equal second retains its earlier index. Empty rectangles
write nothing. No state survives outside caller-owned arrays.

The two primary scans use disjoint stored partitions, documented in
[`FUN_180078a70`](FUN_180078a70.md). The reverse reducer is
[`FUN_180079060`](FUN_180079060.md). Matrix consumers are
[`FUN_180074ba0`](FUN_180074ba0.md) and
[`FUN_180075220`](FUN_180075220.md).
